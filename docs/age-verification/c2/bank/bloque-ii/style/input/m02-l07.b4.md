- a) El nombre del dispositivo y el de su modelo, que se ven en Acerca de
- b) Las letras de las unidades de red asignadas con Asignar unidad de red
- c) Las alarmas y los temporizadores que ofrece la aplicación Reloj

## m02-l07-q182
¿Cuál de las siguientes rutas lleva a la configuración del Historial de archivos en Windows 11?
- a) Panel de control › Sistema y seguridad › Herramientas de Windows
- b) Configuración › Sistema › Almacenamiento › Historial de archivos
- c) Configuración › Cuentas › Copias de seguridad de Windows
- d) Panel de control › Sistema y seguridad › Guardar copias de seguridad de los archivos con Historial de archivos  ✓
Cita: fuente: `ms-win-historial-archivos.html`; «Configurar el historial de archivos»
Explicación: La página dice que, en el Panel de control, en Sistema y seguridad, se selecciona Guardar copias de seguridad de los archivos con Historial de archivos. Herramientas de Windows es una carpeta con herramientas para administradores, y Almacenamiento muestra el espacio en disco. Copias de seguridad de Windows es otra herramienta de copia, distinta del Historial de archivos.
