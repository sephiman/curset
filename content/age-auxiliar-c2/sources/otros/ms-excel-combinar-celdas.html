    Combinar y anular la combinación de celdas en Excel

    Se aplica a
    Excel para Microsoft 365 Excel para Microsoft 365 para Mac Excel 2024 Excel 2024 para Mac Excel 2021 Excel 2021 para Mac Excel 2019 Excel 2016 Aplicación web de Excel
    Obtener ayuda con Copilot
    ¿Cómo puedo dividir el texto de una celda en varias celdas? ¿Cómo fusiono y separo celdas?
    • Windows
    • macOS
    • Web

    No puede dividir una celda individual, pero puede hacer que una celda parezca estar dividida combinando las celdas superiores.

    Combinar celdas

    1. Seleccione las celdas que quiera combinar.

    2. Seleccione Combinar & centro y, a continuación, Combinar celdas.

      Importante

      Al combinar varias celdas, aparece el contenido de una sola celda (la celda superior izquierda para los idiomas de izquierda a derecha o la celda superior derecha para los idiomas de derecha a izquierda) en la celda combinada. El contenido de las demás celdas que se combinen se elimina.

    Separar celdas

    1. Haga clic en la flecha abajo de Combinar y centrar.
    2. Seleccione Anular combinación de celdas.

    Importante

    • No puede dividir una celda sin combinar. Si busca información sobre cómo dividir el contenido de una celda sin combinar en varias celdas, vaya a Distribuir el contenido de una celda en columnas adyacentes.
    • Después de combinar celdas, puede dividir una celda combinada en celdas separadas de nuevo. Si no recuerda dónde ha combinado las celdas, puede usar el comando Buscar para localizar rápidamente las celdas combinadas.

    En la combinación se combinan dos o más celdas para crear una nueva celda de mayor tamaño. Esta es una manera fantástica de crear una etiqueta que abarque varias columnas.

    En el ejemplo siguiente, las celdas A1, B1 y C1 se combinaron para crear la etiqueta "Ventas mensuales" para describir la información de las filas 2 a 7.

    Combinar celdas

    Siga estos pasos para combinar dos o más celdas:

    1. Seleccione dos o más celdas adyacentes que quiera combinar.

      Importante

      Asegúrese de que los datos que desea conservar estén en la celda superior y tenga en cuenta que se eliminarán todos los datos de las otras celdas combinadas. Para conservar los datos de esas otras celdas, simplemente cópielos en otra ubicación en la hoja de cálculo, antes de realizar la combinación.

    2. En la pestaña Inicio , seleccione Combinar & centro y luego Combinar celdas.

    Recomendación

    • Si Combinar & centro está deshabilitado, asegúrese de que no está editando una celda y de que las celdas que desea combinar no tienen el formato de una tabla de Excel. Las celdas con formato de tabla normalmente muestran filas sombreadas alternas y, en ocasiones, flechas de filtro en los encabezados de columna.
    • Para combinar celdas sin centrar, seleccione la flecha situada junto a Combinar & centro y, a continuación, seleccione Combinar entre o Combinar celdas.

    Separar celdas

    Si necesita invertir una combinación de celdas, seleccione la celda combinada y, a continuación, elija el elemento Separar celdas en el menú Combinar & Centro .

    Dividir el texto de una celda en varias celdas

    Puede tomar el texto en una o más celdas y distribuirlo en varias celdas. Esto es lo contrario de la concatenación, donde se combina texto de dos o más celdas en una celda.

    Por ejemplo, puede dividir una columna que contenga nombres completos en las columnas independientes Nombre y Apellido:

    Siga los pasos siguientes para dividir texto en varias columnas:

    1. Seleccione la celda o columna que contiene el texto que quiere dividir.

      Nota

      Seleccione tantas filas como quiera, pero no más de una columna. Además, asegúrate de que haya suficientes columnas vacías a la derecha para que no se elimine ninguno de tus datos. Si es necesario, simplemente agregue columnas vacías.

    2. Seleccione Texto de datos>en columnas, que muestra el Asistente para convertir texto en columnas.

    3. Seleccione Delimitado>Siguiente.

    4. Marque la casilla Espacio y desactive el resto de las casillas. O bien, marque las casillas de coma y espacio si así es como se divide el texto (como "Reyes, Javiers", con una coma y un espacio entre los nombres). Aparece una vista previa de los datos en el panel de la parte inferior de la ventana emergente.

    5. Seleccione Siguiente y, a continuación, elija el formato de las nuevas columnas. Si no desea el formato predeterminado, elija un formato como Texto y, después, seleccione la segunda columna de datos en la ventana de vista previa de datos y vuelva a seleccionar el mismo formato. Repita este procedimiento para todas las columnas de la ventana de vista previa .

    6. Seleccione el botón situado a la derecha del cuadro de destino para contraer la ventana emergente.

    7. En cualquier lugar del libro, seleccione las celdas en las que quiera incluir los datos divididos. Por ejemplo, si está dividiendo un nombre completo en una columna de nombre y una columna de apellido, seleccione el número adecuado de celdas en dos columnas adyacentes.

    8. Selecciona el botón para expandir la ventana emergente nuevamente y, a continuación, selecciona Finalizar.

    En la combinación se combinan dos o más celdas para crear una nueva celda de mayor tamaño. Esta es una manera fantástica de crear una etiqueta que abarque varias columnas. Por ejemplo, aquí las celdas A1, B1 y C1 se combinaron para crear la etiqueta "Ventas mensuales" para describir la información de las filas 2 a 7.

    Combinar celdas

    1. Seleccione la primera celda y presione Mayús mientras selecciona la última celda del rango que desea combinar.

      Importante

      Asegúrese de que solo una de las celdas del rango tenga datos.

    2. Seleccione Combinar inicio>& Centro y, a continuación, Combinar celdas.
      Si Combinar está atenuado, asegúrese de que no está editando una celda o de que las celdas que quiere combinar no están dentro de una tabla.

      Recomendación

      Para combinar celdas sin centrar los datos, seleccione la celda combinada y, a continuación, seleccione las opciones de alineación izquierda, central o derecha de Alinear.

      Si cambia de parecer, siempre puede deshacer la combinación seleccionando la celda combinada y seleccionando Combinar.

    Separar celdas

    Para anular la combinación de celdas inmediatamente después de combinarlas, presione Ctrl + Z. De lo contrario, haga lo siguiente:

    • Seleccione la celda combinada, seleccione Combinar>& Centro y, a continuación, Combinar celdas.
      Los datos de la celda combinada se mueven a la celda izquierda cuando las celdas se dividen.
