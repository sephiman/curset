    Capítulo 1: Introducción al Narrador

    Se aplica a
    Windows 10
    Obtener ayuda con Copilot
    ¿Puedo usar el capítulo 1: introducción al narrador? ¿Qué hago si no puedo obtener un resumen rápido de una página web? Ayúdame a narrar o comenzar rápidamente.
    • Windows 11
    • Windows 10

    El Narrador te permite usar el PC sin ratón para completar tareas comunes si eres invidente o tienes visión reducida. Lee e interactúa con elementos en la pantalla, como texto y botones. Usa el Narrador para leer y escribir correo electrónico, navegar por Internet y trabajar con documentos. 

    Comandos específicos que te permiten navegar por Windows, la web y las aplicaciones. La navegación está disponible con los títulos, vínculos, puntos de referencia y mucho más. Puedes leer el texto (incluida la puntuación) por página, párrafo, línea, frase, palabra y carácter, así como determinar características tales como la fuente y el color del texto. Revisa las tablas de manera eficaz con la navegación de fila y columna.

    Narrador también tiene un modo de navegación y lectura, sobre el que obtendrá más información en Capítulo 3: Uso del modo de examen. Úselo para moverse por Windows 11 usando solo las flechas arriba y abajo del teclado. También puedes usar una pantalla braille para navegar por el PC y leer texto, sobre lo que obtendrás más información en Capítulo 8: Uso del Narrador con braille.

    También puedes personalizar la velocidad, el tono y el volumen de la voz que el Narrador usa e instalar algunas voces de texto a voz de terceros.

    Dos maneras de iniciar y detener el Narrador

    • Para iniciar el Narrador, presiona la tecla + del logotipo de WindowsCtrl + Entrar. Para detener el narrador, vuelve a presionar estas teclas. La tecla del logotipo de Windows se encuentra normalmente en la fila inferior de teclas del teclado, ya sea a la izquierda o a la derecha de la tecla Alt.
    • Para acceder a la configuración del Narrador, usa la tecla + del logotipo de WindowsCtrl + N. A continuación, cambia el botón de alternancia a Usar Narrador.

    Nota

    El icono de accesibilidad aparecerá en la esquina inferior derecha de la pantalla cuando inicies sesión o accedas a menús específicos. Al elegir el icono Accesibilidad , se muestra un menú que contiene un botón de alternancia para el estado de activación/desactivación del narrador. El Narrador se detendrá cuando cierres la sesión o salgas de la pantalla.

    Página principal del Narrador

    Cada vez que actives el Narrador, irás a Inicio del Narrador, que te ofrece un lugar donde puedes abrir todo lo que necesites, tanto si deseas cambiar la configuración del Narrador como aprender los conceptos básicos con el Inicio rápido. Los vínculos de la página principal del Narrador incluyen Inicio rápido, Guía del Narrador (que te lleva a esta guía de usuario en línea), Novedades, Configuración y Comentarios. También puedes controlar si la Página principal de Narrador se abre cuando se inicia el Narrador en configuración de Narrador o con la casilla de verificación de la Página principal de Narrador.

    Aprender sobre el Narrador con Inicio rápido

    La lección de Inicio rápido le guiará a través de los conceptos básicos del uso del Narrador. También hay una página web de muestra para que se acostumbre a usar el Narrador en línea. Muestra, entre otras cosas, cómo usar encabezados y puntos de referencia. Cuando el Narrador está activado, la página principal del Narrador se inicia y es donde puedes acceder al Inicio rápido en cualquier momento.

    Inicia el Narrador automáticamente antes o después de que inicies sesión en el equipo

    • Presiona la tecla + del logotipo de WindowsCtrl + N para abrir la configuración del Narrador.
    • Expanda el botón Mostrar toda la configuración situado junto al botón de alternancia de Narrador para mostrar opciones adicionales.
    • Para iniciar el Narrador automáticamente después de iniciar sesión, selecciona la casilla situada junto a Iniciar el Narrador después de iniciar sesión.
    • Para iniciar el Narrador automáticamente antes del inicio de sesión para todos los usuarios, selecciona la casilla situada junto a Iniciar el Narrador antes del inicio de sesión.

    Dos maneras de iniciar y detener el Narrador

    • Presione la tecla + del logotipo de Windows, Ctrl + Entrar, juntas para iniciar el Narrador. Presiona estas teclas de nuevo para detener el Narrador. (En versiones anteriores de Windows, el comando era la tecla del logotipo de Windows+ Enter.) En muchos teclados, la tecla del logotipo de Windows se encuentra en la fila inferior de teclas, a la izquierda o la derecha de la tecla Alt.

Seleccionar el icono accesibilidad abre un menú con unbotón de alternanciaque se puede usar para activar o desactivar el Narrador. El Narrador se desactivará una vez que inicies sesión o salga de la pantalla.

    Inicia el Narrador automáticamente antes o después de que inicies sesión en el equipo

    1. Presiona la tecla + del logotipo de WindowsCtrl + N para abrir la configuración del Narrador.
    2. Para iniciar el Narrador automáticamente después de iniciar sesión, selecciona la casilla situada junto a Iniciar el Narrador después de iniciar sesión por mí.
    3. Para iniciar el Narrador automáticamente antes de iniciar el inicio de sesión para todos los usuarios, selecciona la casilla situada junto a Iniciar el Narrador antes de iniciar sesión para todos los usuarios.
