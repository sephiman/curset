## Retired features

- **WordPad**: removed from all editions from Windows 11, version 24H2; Microsoft recommends Word for rich text and the
  Bloc de notas for plain text (`ms-win-desuso.html`). One line in «Bloc de notas».
- **Grabación de acciones de usuario / Grabadora de pasos**: no longer updated and to be removed; Recortes recommended for
  screen recording (`ms-win-desuso.html`). One line.
- **Herramientas administrativas**: renamed «Herramientas de Windows» in Windows 11 (`ms-win-herramientas-windows.html`).
  One line.
- **Explorer ribbon** (2024 X 53, Inicio › Modificar): not described; the programme does not name it.

## Summary proposal (course.yaml)

El Explorador de archivos de Windows 11: diseños, extensiones, menú contextual, rutas UNC, Inicio, Acceso rápido y
Este equipo. Gestión de archivos con sus teclas, búsqueda con indexación y Buscar en Windows. Accesorios (Bloc de notas,
Recortes, Paint, Calculadora) y herramientas del sistema (Administrador de tareas, Visor de eventos, Historial de
archivos).

## Cuts made for length

- Partes de la ventana del Explorador (pestañas, paneles, barra de estado) (`ms-win-explorador-lector.html`).
- Ctrl+Mayús+1…9 for views (2, iconos grandes; 6, detalles), Ctrl+T / Ctrl+W tabs, Alt+Flecha arriba, Mayús+F10,
  selection keys (Mayús+teclas de dirección; Ctrl+tecla de dirección+Barra espaciadora) (`ms-win-atajos.html`).
- Formats in Windows 11 24H2 (ZIP, RAR, 7z, TAR; no encrypted archives) (`ms-win-comprimir.html`).
- \\localhost lists shared folders; «Volver a conectar al iniciar sesión» (`ms-win-compartir-red.html`).
- Cloud search from Inicio del Explorador (accounts in Configuración › Cuentas) (`ms-win-explorador.html`).
- Index details: first run takes a couple of hours; index under 10 % of indexed files (`ms-win-indexacion.html`).
- Acerca de content (name, model, edition, version, processor, RAM, 32/64 bits): page «Encontrar información sobre el
  dispositivo Windows» downloaded, then dropped and not saved.
- Recortes: autosave to Capturas de pantalla, Acciones de texto (OCR), Retraso; Paint: capas and IA background removal;
  Calculadora: convertidores detail and «Mantener en la parte superior» (Alt+Flecha arriba, Standard only); Reloj:
  four preset timers, Posponer/Descartar.
- Información del sistema (msinfo32), Configuración del sistema (MSConfig), Administración de equipos (compmgmt.msc),
  eventvwr.msc / regedit run commands (`ms-win-herramientas-sistema.html`); Restaurar from OneDrive cloud: cloud-deleted
  files do not reach the Papelera (`ms-onedrive-restaurar.html`).
- Two LQMC candidates replaced to keep ten lines: Restaurar (2022 50) and Unidad de recuperación (2024 X 52), both kept
  as items.
