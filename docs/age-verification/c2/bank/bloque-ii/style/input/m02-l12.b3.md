## m02-l12-q121
Según el glosario de INCIBE, ¿qué puede significar un ataque contra la privacidad de los usuarios relacionado con las cookies?
- a) Que lleven el control de usuarios para no repetir la contraseña
- b) Que se almacenen en el equipo del usuario en lugar de en el servidor
- c) Que cifren el tráfico entre el navegador y el servidor del sitio
- d) Que recaben información sobre los hábitos de navegación del usuario  ✓
Cita: fuente: `incibe-glosario-ciberseguridad.pdf`; «2.3.29. Cookie»
Explicación: Una de las funciones de las cookies es recabar información sobre los hábitos de navegación del usuario, lo que puede ser un ataque contra la privacidad, por lo que hay que tener cuidado con ellas. Llevar el control de usuarios es la función que evita repetir el usuario y la contraseña, no la que puede atacar la privacidad. Almacenarse en el equipo del usuario es su forma de funcionar; el riesgo para la privacidad viene de recabar los hábitos de navegación. Cifrar el tráfico entre navegador y servidor es lo que hace HTTPS, no las cookies.

## m02-l12-q122
¿Cuál de las siguientes definiciones corresponde al session hijacking, según el glosario de términos de ciberseguridad de INCIBE?
- a) Una medida de seguridad que añade una capa al DNS para comprobar la integridad de los datos
- b) Un ataque que intercepta la sesión de un usuario para acceder a su información o servicios sin autorización  ✓
- c) Una técnica que suplanta a una entidad con un correo para conseguir credenciales o datos de tarjeta
- d) Un ataque que envía un gran número de paquetes ICMP de gran tamaño para sobrecargar la red
Cita: fuente: `incibe-glosario-ciberseguridad.pdf`; «2.18.9. Session Hijacking»
Explicación: El session hijacking es un ataque basado en interceptar la sesión de un usuario en Internet para acceder a su información o servicios sin autorización. Enviar paquetes ICMP de gran tamaño para sobrecargar la red es la inundación ICMP. Suplantar a una entidad por correo para obtener credenciales es el phishing. Añadir una capa de seguridad al DNS para comprobar la integridad es lo que hace DNSSEC.
