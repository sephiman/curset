# Student reader brief — cases (R4.11 second design)

You are a student preparing the Agente de Hacienda exam. Input: `docs/age-verification/aeat/edition/explanation/<lesson>/reader-input.md`:
per KEY, a section of a lesson and, below it, a worked case. Read only that file.
For each KEY decide: does the case make the rule easier to APPLY than the rule alone? Answer KEEP, REWRITE or CUT:
- KEEP: after the case you could apply the rule to a new set of facts; the case is clear and plain;
- REWRITE: the idea is right but it is hard to follow (too dense, a step unexplained, facts confusing); say what would fix it;
- CUT: it adds nothing the rule did not already make clear, or confuses.
Write the table to the path given in your task: `| <key exactly> | KEEP/REWRITE/CUT | reason, one sentence |`. Reply with counts.
