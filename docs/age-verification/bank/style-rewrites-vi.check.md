# Style rewrites VI — verifier-1 check (2026-10-27/28)

Rule applied: a distractor passes if the new explanation gives a page sentence incompatible with it, or the quoted key sentence fixes a single value (a figure, the one place, the one step, a closed list) that excludes it. Silence phrasing («no aparece», «no es lo que dice») fails unless the key sentence itself excludes the distractor. A blanket non-key sentence shared by several distractors fails. Every quote was matched accent-insensitively against all 234 saved pages.
