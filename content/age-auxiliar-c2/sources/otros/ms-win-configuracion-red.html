    Comprender y explorar la configuración de Windows

    Este artículo está destinado a personas que usan un programa de lector de pantalla como Narrador de Windows, JAWS o NVDA con características o herramientas de Windows y productos de Microsoft 365. Este artículo forma parte del conjunto de contenido de Ayuda y formación de accesibilidad donde podrá encontrar más información sobre accesibilidad en nuestras aplicaciones. Para obtener ayuda general, visite Soporte técnico de Microsoft.

    Nota

    Para obtener más información sobre los lectores de pantalla, vaya a Cómo funcionan los lectores de pantalla con Microsoft 365.

    • Windows 11
    • Windows 10

    La aplicación Configuración de Windows 11 ofrece un concentrador centralizado para administrar y personalizar las preferencias del dispositivo. Esto incluye categorías como Sistema, Dispositivos de & Bluetooth, Red & Internet, Personalización, Aplicaciones, Cuentas, Idioma de & de tiempo, Accesibilidad, Seguridad & privacidad, Juegos y Windows Update. Esta guía proporciona una descripción detallada de las categorías de configuración de la aplicación Configuración.

    Abrir Configuración de Windows

    Presiona la tecla Windows+ I para abrir la ventana de configuración de Windows. El lector de pantalla lee "Ventana Configuración, cuadro de búsqueda; buscar una opción de configuración".

    Para obtener más información, ve a Usar un lector de pantalla para explorar y navegar por Configuración en Windows.

    Navegar por las categorías de configuración

    1. Abre la aplicación Configuración y usa la tecla Tabulador para mover el foco a la configuración del sistema .

    2. Para navegar entre categorías, presione la tecla de flechaarriba o abajo y, después, presione Entrar para abrirla.

    3. Use la tecla TAB y las teclas de dirección para desplazarse por las opciones de la sección seleccionada y presione la tecla Retroceso para volver a la ventana Configuración.

      Nota

      Para buscar una configuración específica, presione Ctrl+E. El foco se mueve al cuadro de búsqueda de la ventana Configuración. Use las teclas de dirección para examinar los resultados de la búsqueda y presione Entrar para abrir la configuración seleccionada.

    Navegar por la configuración del sistema

    La sección Sistema de la aplicación Configuración te permite administrar funciones esenciales, como la pantalla, el sonido, las notificaciones, el almacenamiento y la configuración de energía, lo que garantiza que el dispositivo funcione sin problemas y de manera eficaz.

    Pasos para navegar por la configuración del sistema

    1. Abre la aplicación Configuración, presiona la tecla Tab hasta que oigas "Sistema" y presiona Entrar.
    2. Usa la tecla de flecha arriba o abajo para explorar las opciones de administración de la configuración de pantalla, sonido, notificaciones, energía y almacenamiento.

    Nota

    • Los usuarios de dispositivos Surface pueden usar la aplicación Surface para personalizar su interacción con el dispositivo. La configuración disponible y las opciones de personalización dependen del tipo específico de dispositivo Surface que se use.
    • Si no tienes instalada la app Surface, puedes descargarla desde Microsoft Store. Cuando se haya descargado, selecciona Inicio, busca Surface y, a continuación, selecciona la aplicación en la lista de resultados.

    Para explorar algunas de las opciones de configuración del sistema más usadas, como la pantalla, el Portapapeles, las notificaciones, el uso compartido de pantalla y la proyección, y la administración de energía, consulte los artículos siguientes:

    • Cambiar el brillo y el color de la pantalla en Windows
    • Cambiar la configuración rápida y de notificaciones en Windows
    • Usar el Portapapeles
    • Creación de reflejo de pantalla y proyección en su PC o inalámbrica
    • Compartir con dispositivos cercanos en Windows

    Navegar por la configuración de Bluetooth y dispositivos

    La sección Bluetooth y dispositivos te permite administrar los dispositivos conectados al equipo, incluidos periféricos inalámbricos, como mouse, teclados, altavoces, auriculares y mucho más.

    Además, esta sección incluye la función Enlace Móvil en la página Dispositivos móviles, que te permite conectar tu Android o iPhone a tu PC.

    Pasos para navegar por la configuración de Bluetooth y dispositivos

    1. Abre la aplicación Configuración y usa la tecla Tabulador para mover el foco a la configuración del sistema .
    2. Presione la tecla de flecha abajo hasta que oiga "Bluetooth y dispositivos" y, después, presione Entrar.
    3. Usa la tecla de flechaarriba o abajo para explorar las opciones disponibles para conectar, quitar o administrar dispositivos.

    Nota

    • Los usuarios de dispositivos Surface pueden usar la aplicación Surface para personalizar su interacción con el dispositivo. La configuración disponible y las opciones de personalización dependen del tipo específico de dispositivo Surface que se use.
    • Si no tienes instalada la app Surface, puedes descargarla desde Microsoft Store. Cuando se haya descargado, selecciona Inicio, busca Surface y, a continuación, selecciona la aplicación en la lista de resultados.

    Para explorar algunas de las opciones de configuración más usadas de Bluetooth y dispositivos, como el mouse, el teclado, los dispositivos auditivos y la conexión del teléfono, consulta los artículos siguientes:

    • Facilitar el uso del mouse, el teclado y otros dispositivos de entrada
    • Usar un lector de pantalla para emparejar un dispositivo Bluetooth en Windows
    • Uso de dispositivos auditivos con tu PC Windows 11
    • Usar un lector de pantalla para navegar Enlace Móvil

    Navegar por la configuración de Red e Internet

    La sección Red e Internet le permite administrar la conectividad de su dispositivo, incluyendo la configuración de Wi-Fi, Ethernet, zonas con cobertura inalámbrica móvil y modo avión.

    Además, esta sección incluye opciones de configuración para las conexiones de acceso telefónico, que le permiten configurar y editar las conexiones de acceso telefónico local directamente desde la aplicación Configuración. Se han realizado mejoras en la configuración de acceso telefónico para permitir realizar cambios y administrar las conexiones dentro de la aplicación Configuración.

    Pasos para navegar por la configuración de Red e Internet

    1. Abre la aplicación Configuración y usa la tecla Tab para mover el foco a Configuración del sistema .
    2. Presione la tecla de dirección abajo hasta que oiga "Red e Internet" y, después, presione Entrar.
    3. Usa la tecla de flechaarriba o abajo para explorar las opciones de conexión a redes, solución de problemas de conectividad o administración del uso de datos.

    Para obtener información sobre cómo conectarse a una red Wi-Fi, consulta Conectarse a una red Wi-Fi en Windows y Configurar una red inalámbrica en Windows.

    Navegar por la configuración de personalización

    La sección Personalización te permite personalizar la apariencia del dispositivo, incluyendo temas, fondos, colores, pantalla de bloqueo, configuración de la barra de tareas y mucho más. Estas características le permiten crear una experiencia de escritorio única y visualmente atractiva adaptada a sus preferencias.

    También puedes administrar la configuración de entrada de texto para personalizar el teclado en pantalla y la información de escritura, optimizando la experiencia de escritura para adaptarla a tus necesidades. La sección Fuentes le permite ver las fuentes instaladas o agregar otras nuevas, lo que permite una mayor personalización del estilo de texto en todo el dispositivo.

    Además, la configuración de personalización incluye características como Tiempo interactivo en pantalla de bloqueo y Contenido destacado del escritorio, que ofrecen opciones para mejorar la pantalla de bloqueo con actualizaciones meteorológicas en tiempo real o rotando imágenes y detalles. Si quieres ajustar la forma en que usas el dispositivo para obtener sugerencias personalizadas, anuncios y recomendaciones dentro de la experiencia de Microsoft, ve a la configuración de Uso de dispositivos en la aplicación Configuración para ver más opciones de personalización.

    Pasos para navegar por la configuración de personalización

    1. Abre la aplicación Configuración y usa la tecla Tab para mover el foco a Configuración del sistema .
    2. Presione la tecla de dirección abajo hasta que oiga "Personalización" y, después, presione Entrar.
    3. Usa la tecla de flechaarriba o abajo para explorar las opciones de actualización de la apariencia del dispositivo según tus preferencias.

    Para explorar algunas opciones de configuración de personalización usadas habitualmente, como la pantalla de bloqueo o la iluminación dinámica, consulta los siguientes artículos:

    • Personalizar la pantalla de bloqueo
    • Mejorar la visualización de Windows

    Navegar por la configuración de aplicaciones

    La sección Aplicaciones le permite administrar los programas instalados en el dispositivo. Esto incluye desinstalar y administrar aplicaciones y establecer programas predeterminados. Esta sección proporciona acceso a la configuración de mapas sin conexión, que te permiten descargar mapas para su uso sin conexión a Internet, y aplicaciones para sitios web, donde puedes controlar qué aplicaciones abren vínculos web.

    Además, la configuración de inicio te permite administrar qué aplicaciones se inician automáticamente cuando se inicia el dispositivo, lo que ayuda a optimizar el rendimiento.

    Pasos para navegar por la configuración de aplicaciones

    1. Abre la aplicación Configuración y usa la tecla Tab para mover el foco a Configuración del sistema .
    2. Presione la tecla de dirección abajo hasta que oiga "Aplicaciones" y, después, presione Entrar.
    3. Usa la tecla de flechaarriba o abajo para explorar las opciones de administración de las aplicaciones instaladas, la configuración avanzada de las aplicaciones y el comportamiento de inicio.

    Para explorar algunas opciones de configuración de aplicaciones usadas habitualmente, como desinstalar aplicaciones, configuración de inicio y mapas sin conexión, consulte los siguientes artículos:

    • Desinstalar o quitar aplicaciones y programas en Windows
    • Configurar aplicaciones de inicio en Windows
    • Encontrar el camino con Mapas

    Navegar por la configuración de la cuenta

    La sección Cuentas le permite administrar cuentas de usuario, opciones de inicio de sesión y preferencias de cuenta. Puede elegir iniciar sesión con una cuenta personal, profesional o educativa, lo que garantiza un acceso perfecto a los recursos y la configuración entre dispositivos.

    Esta sección ofrece opciones para mejorar la seguridad personalizando métodos de inicio de sesión, como Windows Hello (reconocimiento facial, huella digital o PIN), contraseñas tradicionales y claves de seguridad. Además, puede configurar el correo electrónico y la cuenta para las aplicaciones conectadas, lo que habilita la sincronización de correos electrónicos, calendarios y contactos.

    También puedes usar la configuración de Copias de seguridad de Windows de esta sección para hacer una copia de seguridad de tus archivos, preferencias y configuraciones importantes en la nube, lo que garantiza que puedas restaurarlos fácilmente en un dispositivo nuevo o existente.

    Pasos para navegar por la configuración de cuentas

    1. Abre la aplicación Configuración y usa la tecla Tab para mover el foco a Configuración del sistema .
    2. Presione la tecla de flecha abajo hasta que oiga "Cuentas" y, después, presione Entrar.
    3. Use la tecla de flechaarriba o abajo para explorar las opciones relacionadas con la cuenta.

    Para explorar algunas opciones de configuración de cuenta usadas habitualmente, como las opciones de inicio de sesión, la copia de seguridad y la restauración de datos, consulte los siguientes artículos:

    • Usar un lector de pantalla para realizar copias de seguridad y restaurar datos en Windows
    • Configurar Windows Hello
    • Usar Windows Hello con un lector de pantalla

    Navegar por la configuración de hora e idioma

    La sección Hora e idioma incluye la configuración de fecha y hora, idioma y región, escritura y voz (el idioma y las opciones de voz del dispositivo). Puedes ajustar la zona horaria, habilitar las actualizaciones automáticas para la configuración de hora, configurar los idiomas de pantalla preferidos y administrar las preferencias de entrada y voz.

    Además, la configuración de escritura le permite personalizar su experiencia de escritura con características como la autocorrección, sugerencias de texto y opciones de entrada multilingüe. Las características de escritura y voz de Windows mejoran la eficiencia de la escritura al proporcionar información, como correcciones ortográficas y gramaticales, sugerencias de texto predictivo y mucho más, lo que mejora la productividad general.

    Pasos para navegar por la configuración de hora e idioma

    1. Abre la aplicación Configuración y usa la tecla Tab para mover el foco a Configuración del sistema .
    2. Presione la tecla de flecha abajo hasta que oiga "Hora e idioma" y, después, presione Entrar.
    3. Usa la tecla de flechaarriba o abajo para explorar las opciones de administración de la configuración de tiempo, las preferencias de idioma y las configuraciones de voz.

    Para explorar algunas de las opciones de configuración de hora e idioma más usadas, como la fecha y hora, el idioma y la región, la escritura y la voz, consulte los artículos siguientes:

    • Cómo establecer la hora y la zona horaria
    • Habilitar sugerencias de texto en Windows

    • Usar el reconocimiento de voz en Windows

    Navegar por la configuración de juegos

    La sección Juegos le permite personalizar la configuración para una experiencia de juego mejorada, incluida la configuración de la Barra de juegos para capturar y compartir el juego, administrar capturas para grabar y guardar su ubicación, y habilitar el modo de juego para optimizar el rendimiento del sistema durante las sesiones de juego.

    Pasos para navegar por configuración de juegos

    1. Abre la aplicación Configuración y usa la tecla Tab para mover el foco a Configuración del sistema .
    2. Presione la tecla de dirección abajo hasta que oiga "Juegos" y, después, presione Entrar.
    3. Usa la tecla de flechaarriba o abajo para explorar las opciones de personalización de la Barra de juegos, el ajuste de la configuración de captura y la habilitación del modo de juego.

    Navegar por la configuración de accesibilidad

    La sección Accesibilidad proporciona una amplia variedad de opciones de configuración diseñadas para facilitar el uso de Windows. El sistema organiza estos ajustes en tres secciones principales:

    1. Visión: Esta sección incluye opciones para ajustar el tamaño del texto, habilitar efectos visuales, personalizar el puntero del mouse e indicador táctil, configurar el cursor de texto, usar la Lupa, aplicar filtros de color, activar temas de contraste y usar el lector de pantalla Narrador.
    2. Audición: Esta sección ofrece opciones para administrar opciones relacionadas con el audio, configurar dispositivos auditivos y habilitar subtítulos.
    3. Interacción: Esta sección permite personalizar la voz, el teclado, el mouse y el control ocular para una interacción del dispositivo más eficaz.

    Pasos para navegar por la configuración de accesibilidad

    1. Abre la aplicación Configuración y usa la tecla Tab para mover el foco a Configuración del sistema .
    2. Presione la tecla de dirección abajo hasta que oiga "Accesibilidad" y, después, presione Entrar.
    3. Usa la tecla de flechaarriba o abajo para explorar la configuración disponible para las características de visión, audición e interacción.

    Para obtener más información sobre la configuración de accesibilidad, como el tamaño del texto, los filtros de color, el cursor de texto, los dispositivos auditivos, la voz, el teclado y el mouse, consulte los siguientes artículos:

    Navegar por la configuración de privacidad y seguridad

    La sección Privacidad y seguridad le permite administrar las funciones de privacidad y seguridad de los datos de su dispositivo. Esto incluye la configuración de los permisos de las aplicaciones, donde puedes controlar a qué información pueden acceder las aplicaciones, y la seguridad de Windows, que ayuda a proteger tu dispositivo con herramientas como el antivirus, el firewall y el cifrado de dispositivo.

    1. Abre la aplicación Configuración y usa la tecla Tab para mover el foco a Configuración del sistema .
    2. Presione la tecla de flecha abajo hasta que oiga "Privacidad y seguridad" y, después, presione Entrar.
    3. Usa la tecla de flechaarriba o abajo para explorar las opciones de administración de preferencias de privacidad y mejora de la seguridad de tu dispositivo.

    1. Abre la aplicación Configuración y usa la tecla Tab para mover el foco a Configuración del sistema .
    2. Presione la tecla de dirección abajo hasta que oiga "Windows Update" y, después, presione Entrar.
    3. Usa las teclas de flechaarriba o abajo para explorar las opciones de administración de la configuración de actualización y la programación de reinicios.
