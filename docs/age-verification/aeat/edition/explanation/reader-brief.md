# Student reader brief — explanation layer (R4.11)

You are a student preparing the AEAT Agentes exam who has not studied the topic. Read the lesson file given to you top to bottom,
as a student would. You do not need to judge legal accuracy (others did). For each «En pocas palabras.» paragraph and for the
overview, answer as the student:
- Did it help you understand what the rule is for, when it applies, what changes when a condition fails, or how it differs from its
  neighbour — BEFORE you read the literal sentences below it?
- OK: it does.
- REWRITE: it only repeats the rule below in other words (you learned nothing the literal text does not say), or it cannot be
  understood without reading the rule first (jargon, a pronoun with no antecedent, an unexplained abbreviation), or it is
  confusing. Say in one sentence what a better paragraph would explain.
- CUT: nothing in it is worth keeping, or the literal text is already plain.
Also flag any sentence that sounds like a model wrote it (filler, triads, summary closers, rhetorical question) as a note.
Write a table to the output file, one row per paragraph, exactly: `| <key> | OK or REWRITE or CUT | reason |`, where <key> is
`overview` for the overview and `after:<heading line>#1` for a paragraph (the heading line it follows, copied exactly, e.g.
`after:### Plazos de pago#1`). Edit nothing else. Reply with the counts and the REWRITE/CUT keys.
