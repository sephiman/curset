    Funciones de Excel (por categoría)

    Se aplica a
    Excel para Microsoft 365 Excel para Microsoft 365 para Mac Excel 2024 Excel 2024 para Mac Excel 2021 Excel 2021 para Mac Excel 2019 Excel 2016

    Las funciones de hojas de cálculo se categorizan según su función. Haga clic en una categoría para explorar sus funciones. O bien, presione Ctrl+F para buscar una función escribiendo las primeras letras o una palabra descriptiva. Para obtener información detallada sobre una función, haga clic en su nombre en la primera columna.

    Nuestras 10 funciones destacadas

    Estas son nuestras 10 funciones destacadas que creemos que mejorarán tu experiencia con la hoja de cálculo.

    Función Descripción
    SUMA Use esta función para agregar los valores de las celdas.
    SI Use esta función para devolver un valor si una condición es verdadera y otro valor si es falsa. Aquí puede ver un vídeo acerca del uso de la función SI.
    SUMAR.SI.CONJUNTO Use esta función cuando necesite agregar las celdas de un rango que cumplen varios criterios.
    XLOOKUP Use esta función cuando necesite buscar en un rango o una matriz y devolver un elemento que corresponda a la primera coincidencia que encuentre. Si no hay ninguna coincidencia, BUSCARX puede devolver la coincidencia más cercana (aproximada).
    CONTAR.SI.CONJUNTO Use esta función para contar el número de celdas, dentro del rango, que cumplen varios criterios.
    CONTAR Use esta función para contar cuántos números hay en la lista de argumentos. Puede usar CONTARA para contar cuántos valores hay en la lista de argumentos.
    LET Use esta función para asignar nombres a los resultados de los cálculos.
    FILTRAR Use esta función para filtrar un rango de datos basándose en los criterios que defina.
    UNIQUE Use esta función para devolver una lista de valores únicos de una lista o rango.
    TEXTOANTES Use esta función para devolver el texto que aparece antes de una cadena o un carácter determinado. Puede usar TEXTAFTERpara devolver texto que aparece después de un carácter o cadena determinados.

    Compatibilidad

    En las versiones más recientes de Excel, estas funciones se han sustituido por funciones nuevas que proporcionan precisión mejorada y tienen nombres que reflejan mejor su uso. Aún puede usarlas para la compatibilidad con versiones anteriores de Excel pero, si la compatibilidad con versiones anteriores no es obligatoria, debería empezar a usar las funciones nuevas en su lugar. Para obtener más información sobre las funciones nuevas, consulte Funciones estadísticas (referencia) y Funciones matemáticas y trigonométricas (referencia) .

    Cubos

    Función Descripción
    MIEMBROKPICUBO Devuelve una propiedad de indicador clave de rendimiento (KPI) y muestra el nombre del KPI en la celda. Un KPI es una medida cuantificable, como los beneficios brutos mensuales o la facturación trimestral por empleado, que se usa para supervisar el rendimiento de una organización.
    MIEMBROCUBO Devuelve un miembro o tupla del cubo. Se usa para validar la existencia del miembro o la tupla en el cubo.
    PROPIEDADMIEMBROCUBO Devuelve el valor de una propiedad de miembro del cubo. Se usa para validar la existencia de un nombre de miembro en el cubo y para devolver la propiedad especificada para este miembro.
    MIEMBRORANGOCUBO Devuelve el miembro n, o clasificado, en un conjunto. Se usa para devolver uno o más elementos de un conjunto, por ejemplo, el cantante que más discos vende o los 10 mejores alumnos.
    CONJUNTOCUBO Define un conjunto calculado de miembros o tuplas mediante el envío de una expresión de conjunto al cubo en el servidor, lo que crea el conjunto y, después, devuelve dicho conjunto a Microsoft Excel.
    RECUENTOCONJUNTOCUBO Devuelve el número de elementos de un conjunto.
    VALORCUBO Devuelve un valor agregado del cubo.
