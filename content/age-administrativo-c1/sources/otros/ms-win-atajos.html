    Métodos abreviados de teclado de Windows

    Se aplica a
    Windows 11 Windows 10
    • Windows 11
    • Windows 10

    Los métodos abreviados de teclado son combinaciones de teclas que proporcionan un modo alternativo para hacer algo que se suele realizar con un ratón. 

    Si estás intentando tomar una captura de pantalla o captura de pantalla, consulta Usar la herramienta Recortes para capturar capturas de pantalla.

    Nota

    • El comportamiento de algunos métodos abreviados de teclado puede variar en diferentes aplicaciones. Por ejemplo, es posible que Ctrl+Mayús V+ para pegar como texto sin formato no funcione en todas las aplicaciones.
    • Algunas aplicaciones pueden cambiar el comportamiento de algunos métodos abreviados de teclado. En este artículo se enumeran los métodos abreviados de teclado predeterminados de Windows.

    Métodos abreviados de teclado de Windows en general y para escritorio

    Use los siguientes métodos abreviados de teclado para abrir, cerrar, navegar y realizar otras tareas de forma eficaz en el entorno de escritorio de Windows.

    Para ver los métodos abreviados de teclado relacionados con la barra de tareas de Windows, consulta Métodos abreviados de la barra de tareas. Para ver los métodos abreviados de teclado específicos del Explorador de archivos, consulte métodos abreviados del Explorador de archivos.

    Presione esta tecla: Para realizar esta acción:
    Alt+A Establezca el foco en el primer icono del menú Acciones sugeridas.
    Alt+Esc Desplazarse por las ventanas en el orden en que se abrieron.
    Alt+F4 Cerrar la ventana activa. Si no hay ventanas abiertas, solicite el cierre.
    Alt+F8 Mostrar la contraseña en la pantalla de inicio de sesión.
    Alt+Flecha izquierda Volver.
    Alt+Flecha abajo Mover una pantalla hacia abajo
    Alt+Re Pág Retroceder una pantalla
    Alt+Impr Pant Capture una captura de pantalla de la ventana activa y cópiela en el Portapapeles.
    Alt+Flecha derecha Ir hacia delante.
    Alt+Mayús+teclas de dirección Cuando un grupo o un icono tiene el foco en el menú Inicio, moverlo en la dirección especificada.
    Alt+Ctrl+Insertar Vuelva a colocar el foco en el equipo host desde el Espacio aislado de Windows.
    Alt+Barra espaciadora Abrir el menú contextual de la ventana activa.
    Alt+Tab Cambiar entre ventanas abiertas. Para desplazarse por varias ventanas, mantenga presionada la tecla Alt y presione el tabulador varias veces.
    Alt+letra subrayada Para las acciones en los menús contextuales o de comandos, algunas ventanas y aplicaciones especifican métodos abreviados de teclado subrayando un carácter en el nombre de la acción. Presione Alt y luego la letra para realizar esa acción.
    Ctrl+E Seleccionar todos los elementos de una ventana.
    Ctrl+Alt+Supr Cambie a la pantalla de seguridad, donde puede bloquear el escritorio, cambiar de usuario, cerrar sesión, cambiar una contraseña o abrir el Administrador de tareas.
    Ctrl+Alt+Tab Ver una miniatura de todas las aplicaciones abiertas. Usar las teclas de dirección para cambiar entre aplicaciones abiertas.
    CTRL+Esc Abre el menú Inicio.
    Ctrl+F4 En las aplicaciones que están abiertas a pantalla completa y le permiten tener abiertos varios documentos al mismo tiempo, cierre el documento activo, pero no toda la aplicación.
    Ctrl+F5
    CTRL+D    		 Actualizar la ventana actual.
    Ctrl+Mayús Cuando hay varias distribuciones del teclado disponibles, cambie la distribución del teclado.
    Ctrl+Mayús+teclas de dirección Cuando una ventana tenga el foco en el menú Inicio, muévelo a otra ventana para crear una carpeta.
    Ctrl+Mayús+Esc Abra el administrador de tareas
    Ctrl+barra espaciadora Habilite o deshabilite el Editor de métodos de entrada (IME) para chino. Para obtener más información, consulte el IME de Microsoft en chino simplificado y el IME en chino tradicional de Microsoft.
    Ctrl+Y Rehacer una acción que antes se deshacía con Ctrl+Z.
    Ctrl+Z Deshacer la acción anterior.
    Esc o Escape Detener o salir de la tarea actual, o descartar un cuadro de diálogo.
    F5 Actualizar la ventana activa.
    F6 Desplazarse por los elementos de una ventana o del escritorio.
    F10 Activar la barra de menús en la ventana activa.
    Impr Scn o Impr Pant Seleccione una zona de la pantalla para hacer una captura de pantalla en el portapapeles. A continuación, puedes abrir la herramienta Recortes para compartir o aumentar la imagen.
    Nota: Puede desactivar este comportamiento predeterminado. Selecciona Inicio>,configuración>,Accesibilidad>,Teclado y establece Usar el botón Imprimir pantalla para abrir el recorte de pantalla en Desactivado.
    Abrir la aplicación Configuración

    Métodos abreviados de teclado del símbolo del sistema

    Use los siguientes accesos directos con el símbolo del sistema de Windows.

    Presione esta tecla: Para realizar esta acción:
    Ctrl+C
    Ctrl+Insertar    		 Copiar el texto seleccionado.
    Ctrl+V
    Mayús+Insertar    		 Pegar el texto seleccionado.
    Ctrl+M Acceder al modo de marca.
    Alt+tecla de selección Iniciar la selección en modo de bloque.
    Teclas de dirección Mover el cursor en la dirección especificada.
    Re Pág Subir el cursor una página.
    Av Pág Bajar el cursor una página.

    Ctrl+Flecha abajo Bajar una línea en el historial de salida.
    Ctrl+Inicio (navegación por el historial) Si la línea de comandos está vacía, mueve la ventanilla a la parte superior del búfer. De lo contrario, elimina todos los caracteres a la izquierda del cursor en la línea de comandos.
    Ctrl+Fin (navegación por el historial) Si la línea de comandos está vacía, mueve la ventanilla a la línea de comandos. De lo contrario, elimina todos los caracteres que se encuentran a la derecha del cursor en la línea de comandos.

    TAB Avanzar por las opciones.

    Retroceso Abrir una carpeta de un nivel superior si hay una carpeta seleccionada en el cuadro de diálogo Guardar como o Abrir.
    Teclas de dirección Si la opción activa es un grupo de botones de opción, seleccionar un botón.
