# Ofimática in the official exams — index (Auxiliar, C2)

Round R0a, 2026-11-05. Every question on temas II.5–II.12 of the 2025 programme (informática básica, Windows, Word, Excel, Access, Outlook, Internet) in the six distinct Auxiliar questionnaires: 2025, 2024 ordinario and extraordinario, 2022, OEP 2020 ordinario and extraordinario (files `conv2020_*`). Bloque II temas II.1–II.4 (atención al público, información, registro y archivo, administración electrónica) are not ofimática and are not indexed here; they are in the ledger. Modelo B repeats modelo A in another order: B numbers are given next to A's and questions are not counted twice. There are no Auxiliar extraordinarios for 2025 or 2022.

Classification per question (tema, application, feature family, feature, programme feature, form, version, status) comes from the round's per-exam pass, checked against Windows 11 and Microsoft 365 desktop, the versions Anexo I 2.2 fixes. Feature families group features that test the same thing; they are this index's grouping, reusing the names of C1's index (`docs/age-ofimatica-index.md`) where one fits. Full question text: `content/age-auxiliar-c2/sources/examenes-oficiales/`. Status per question: `docs/age-c2-official-exams-ledger.md`, which is authoritative.

Forms: `atajo`, `ruta de menú/cinta`, `función o fórmula`, `resultado de fórmula`, `concepto/definición`, `comportamiento`, `configuración`, `otro` (as in C1).

**Versions.** 2025 asks about Windows 11 and Microsoft 365. 2024 mixes Windows 10 and 365. 2022 and OEP 2020 name Windows 10 and Office/Excel 2019. The course follows 2025. Older questions are indexed by feature anyway, because most features persist; the «Versión» column gives the version the stem names and section 6 lists the ones whose answer depends on it.

## 6. Retired features, changed labels and version-specific questions

### Retired (excluded from the practice set)

- 2024 extr. P2 39 — Aplicaciones preinstaladas (Visor 3D, El Tiempo, Obtener ayuda). Visor 3D ya no viene instalado en Windows 11 y Microsoft lo retiró; la pregunta solo tiene una respuesta para Windows 10.
- OEP 2020 ord. P2 17 — Accesibilidad: Lupa, Narrador, Reconocimiento de voz. El Reconocimiento de voz de Windows quedó en desuso en 2023 y se retiró a partir de Windows 11 24H2 (lo sustituye Acceso por voz), así que la opción d tampoco es hoy una herramienta de Windows. Igual que C1 conv2020 P1 50.
- OEP 2020 ord. P2 19 — Explorador: Inicio > Mover a. El Explorador de Windows 11 sustituyó la cinta (Inicio > Organizar > Mover a / Copiar a) por la barra de comandos, que no tiene «Mover a»; se mueve con Cortar y Pegar o arrastrando. Mismo criterio que C1 conv2024_X P1 53.
- OEP 2020 extr. P2 3 — Asistente de concentración. En Windows 11 22H2 el Asistente de concentración se sustituyó por «No molestar» (notificaciones) y «Concentración» (sesiones); la pregunta solo se responde para Windows 10. Igual que C1 conv2020_X P1 46.
- OEP 2020 extr. P2 8 — Archivo > Compartir > Presentar en línea. Microsoft indica que «Presentar en línea» (Office Presentation Service) ya no está disponible en la mayoría de versiones de Word para Windows; no figura en Word de Microsoft 365. Igual que C1 conv2020_X P1 54.
- OEP 2020 extr. P2 31 — Accesorios: WordPad y Bloc de notas. WordPad se eliminó de Windows 11 a partir de la versión 24H2 (2024); la comparación con el Bloc de notas ya no es posible. Igual que C1 conv2020_X P1 45.

### Changed labels («Etiqueta actual»; kept with a note)

- 2024 ord. P2 18 (B 18) — Vínculo móvil (Tu Teléfono). Etiqueta actual: Vínculo móvil (antes «Tu Teléfono»). Clave oficial discutida: con iPhone, Vínculo móvil permite mensajes y llamadas pero no ver las fotos; la clave solo es exacta para Android.
- 2024 ord. P2 23 (B 23) — Acceso rápido. Etiqueta actual: en Windows 11 el Explorador abre en «Inicio», con las secciones Acceso rápido (carpetas ancladas y frecuentes) y Recientes; sin confirmar en la interfaz española.
- 2024 extr. P2 38 — Centro de actividades / Centro de notificaciones. Etiqueta actual: en Windows 11, «Centro de notificaciones» (Windows + N o la fecha y hora de la barra de tareas); «Centro de actividades» es el nombre de Windows 10.
- 2024 extr. P2 40 — Agregar columnas (vista Detalles). Etiqueta actual: en Windows 11 no hay botón «Agregar columnas»; las columnas se añaden con clic derecho en el encabezado, en vista Detalles; sin confirmar en la interfaz española.
- 2024 extr. P2 42 — Diagnóstico de memoria de Windows. Etiqueta actual: «Herramientas de Windows» (en Windows 10, «Herramientas administrativas»).
- 2022 P2 16 — Conectarse a una red Wi-Fi. Etiqueta actual: en Windows 11 el icono de red de la barra de tareas abre la Configuración rápida; la flecha junto a Wi-Fi muestra las redes disponibles y el botón Conectar. Sin confirmar en la interfaz española.
- OEP 2020 ord. P2 12 — Administrador de tareas: pestañas. Etiqueta actual: en Windows 11 la pestaña «Inicio» del Administrador de tareas es la página «Aplicaciones de arranque» del menú lateral. La pestaña «Planificación» (c) sigue sin existir.
- OEP 2020 extr. P2 32 — Explorador: pestaña Buscar. Etiqueta actual: el Explorador de Windows 11 no tiene pestaña «Buscar»; al iniciar una búsqueda aparece en la barra de comandos el botón «Opciones de búsqueda». Sin confirmar en la interfaz española.
