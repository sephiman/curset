Explorar InPrivate en Microsoft Edge

Se aplica a
Microsoft Edge Windows 10 Windows 11

Resumen

La ventana de InPrivate en Microsoft Edge le permite navegar por la Web sin guardar el historial de exploración, las cookies, los datos del sitio o las entradas de formularios en su dispositivo. La exploración de InPrivate ayuda a mejorar la privacidad al limitar el seguimiento local y, al mismo tiempo, permitir guardar descargas y favoritos. En este artículo se explica cómo funciona la exploración de InPrivate y cómo usarla para una exploración web más privada.

Al usar las pestañas o ventanas InPrivate, los datos de exploración (por ejemplo, el historial, archivos temporales de Internet y cookies) no se guardan en el equipo cuando terminas.

En Microsoft Edge, seleccione el icono Configuración y más y, después, la ventana Nuevo InPrivate.
