# age-auxiliar-c2, round R0a: working data

Copied from the session scratchpad on 2026-11-05, so the record in `docs/age-c2-*.md` can be traced and regenerated. Handoff: `docs/age-c2-round-0a-handoff.md`.

## Layout

| Folder | Content |
|---|---|
| `parsed/` | The 8 questionnaires parsed to JSON (one per PDF: `sec`, `n`, stem, options a–d). `master.json` holds the 720 distinct questions with their definitive key, kind, and modelo B number. Also: the classifier inputs (`p1_all`, `p1_know`, `p1_psico`, `p2_new`, `p2_old`), the modelo A ↔ B maps (`ab_2024`, `ab_2025`), and `laboratorios.tsv`, the transcription of the «Cuadro Laboratorios» image table. |
| `keys/` | The 8 definitive answer sheets parsed to JSON (`"P1.12": "c"`, …). |
| `classification/` | The per-question classification from the four classifiers: `class_p1_know` (bloque I), `class_psico` (psicotécnicos), `class_p2_new` (2025–2024 part 2) and `class_p2_old` (2022–2020 part 2). Also the brief they shared (`brief_common.md`) and `overrides.json`, the coordinator's corrections and Juanjo's decisions applied on top of them. |
| `scripts/` | `parse_q.py` and `parse_keys.py` parse the `pdftotext -layout` text. `abmap.py` pairs modelo A with modelo B. `gen_ledger.py`, `gen_ofi.py` and `gen_psico.py` write the ledger, the ofimática index and the psicotécnico index. `style_stats.py` and `textstats.py` compute the statistics of the exam style guide. `verify_programa.py` checks `programa.md` against the BOE and CPS text. `calc/` recomputes every psicotécnico item. `norm/` builds `normativa.yaml` (`build.py`, `c2sel.py` maps C1 norms to C2 temas, `currency.py` reads the boe.es «Última actualización» dates). |
| `checks/` | `inap_*`: the PDF links found on the INAP pages and the sha256 match against `sources/`. `ms_*`: the live check of the Microsoft pages (`ms_live_check.json`, text comparison for C1's 182 pages), the pages the classifiers named (`ms_sources.json`) and the copy decision per page (`ms_copy_report.json`). `norm_*`: the normativa build and currency reports. `style_stats.json` and `textstats.json`: the numbers behind the style guide. |

## Rerunning

The scripts ran from the scratchpad root with relative paths (`work/`, `parsed/`, `keys/`, `ms/`). To rerun one, rebuild that tree in a scratch folder:

- `txt/`: `pdftotext -layout` of every PDF in `content/age-auxiliar-c2/sources/`.
- `parsed/` and `keys/`: from this folder.
- `work/`: this folder's `parsed/*.json` (except the 8 questionnaires), `classification/*` and `scripts/*.py`.
- `ms/copy_report.json`: `checks/ms_copy_report.json`.

Then run each script with `python3 -I`. `gen_ledger.py` and `gen_ofi.py` write straight into `docs/`. The exam style guide (`docs/age-c2-exam-style.md`) was written by hand on top of `style_stats.json` and is not regenerated by a script.

Not kept: the INAP and Microsoft downloads used only for hashing and text comparison (175 MB and 14 MB of third-party pages), and the page renders other than the two in `sources/examenes-oficiales/renders/`.
