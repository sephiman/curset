    Más información sobre los grupos en Outlook

    Se aplica a
    Outlook para Microsoft 365 Outlook para Microsoft 365 para Mac Outlook 2024 Outlook 2024 para Mac Outlook 2021 Outlook 2021 para Mac Outlook.com Nuevo Outlook para Windows Outlook en la web para Exchange Server 2016 Outlook en la web para Exchange Server 2019
    Obtener ayuda con Copilot
    ¿Cómo accedo a mi grupo en Outlook mientras estoy fuera? ¿Cómo creo un grupo en Outlook.com? Haz que Copilot simplifique los Grupos en Outlook para mí.

    Los grupos de Microsoft 365 proporcionan herramientas de colaboración para ayudar a sus compañeros de trabajo, amigos o familiares a trabajar en un objetivo común. Independientemente del tipo de cuenta con la que cree un grupo, puede enviar mensajes al grupo con una dirección de correo electrónico dedicada y programar eventos en un calendario de grupo. Agregar miembros del grupo es fácil cuando crea un grupo o los agrega más adelante.

    Al crear un grupo, se crea automáticamente una bandeja de entrada de Outlook compartida, una dirección de correo electrónico de grupo (por ejemplo, sales@contoso.com) y un calendario compartido.

    Al crear un grupo de Microsoft 365 con una cuenta profesional o educativa, amplía automáticamente a los miembros del grupo el acceso a los archivos compartidos en OneDrive, a los chats en Microsoft Teams y a las asignaciones de tareas en Planner.

    Con la experiencia de Grupos en Outlook, los miembros pueden acceder a toda la actividad del grupo en un solo lugar.

    Independientemente de dónde cree su grupo, los miembros pueden interactuar con él en todas las plataformas: en Outlook para Windows o macOS. Los grupos creados con cuentas profesionales o educativas de Microsoft 365 también pueden interactuar con grupos en la aplicación móvil de Outlook.

    En 2024, los grupos tendrán un nuevo aspecto. Obtenga información sobre la nueva experiencia de Grupos de Microsoft 365 en Outlook.

    Un grupo de Microsoft 365 es más que una lista de distribución

    Los Grupos de Microsoft 365 comparten una dirección de correo electrónico de grupo que envía mensajes a todo el grupo. Pero los Grupos de Microsoft 365 no son listas de contactos, también conocidas como listas de distribución. Una lista de contactos es simplemente un conjunto de direcciones de correo electrónico que puede usar para enviar mensajes de correo electrónico o invitaciones a reuniones a todos a la vez. Para obtener más información, consulte ¿Cuál es la diferencia entre un grupo de Microsoft 365 y una lista de contactos en Outlook?

    Diferentes tipos de Grupos de Microsoft 365

    Al crear un grupo de Microsoft 365, se configura una bandeja de entrada compartida y un calendario compartido para todos los usuarios. Los grupos configurados con una suscripción a Microsoft 365 para el trabajo o la escuela también incluyen una colección de recursos compartidos adicionales.

    En función del tipo de cuenta con la que esté configurado, un grupo de Microsoft 365 puede funcionar de diferentes maneras. ¿Qué es la diferencia entre una cuenta de Microsoft o una cuenta profesional o educativa?

    Grupos de Microsoft 365 con cuentas personales

    Si usa grupos con una cuenta personal, como una Outlook.com, Hotmail.com o si usa una cuenta de Gmail o Yahoo, puede crear un grupo, pero no habrá recursos compartidos de OneNote, SharePoint o Planner.

    Enviar correos electrónicos a tu grupo

    Los miembros del grupo pueden seguir la bandeja de entrada del grupo en su propio buzón de correo o pueden elegir ver todos los mensajes en el panel del grupo. Cada persona tiene la oportunidad de ver y responder o reenviar correos electrónicos en el buzón de grupo. Para obtener más información, consulte Enviar un correo electrónico a un grupo en Outlook.

    Calendario compartido con cuentas personales

    Cada miembro del grupo de Outlook tiene acceso a un calendario de grupo compartido. Los miembros pueden agregar eventos al calendario del grupo que todos los miembros del grupo pueden ver. Para obtener más información, vea Usar un calendario de grupo en Outlook para programar y editar eventos.

    Pertenencia a grupos con cuentas personales

    Los miembros del grupo pueden enviar mensajes al grupo mediante la dirección de correo electrónico de grupo único. Outlook.com propietarios de grupos pueden editar un grupo, agregar o quitar miembros y mucho más. Para obtener más información, consulte Agregar, editar y quitar miembros de grupos en Outlook.

    Acceso a su grupo personal desde cualquier lugar

    Independientemente de dónde cree el grupo, los miembros del grupo para su cuenta personal, puede interactuar con él en todas las plataformas: todas las versiones de escritorio o en línea de Outlook, excepto Outlook para iOS y Outlook para Android

    Grupos de Microsoft 365 con cuentas profesionales o educativas

    Nota

    Estas características solo están disponibles para los usuarios que usen una cuenta profesional o educativa con una suscripción a Microsoft 365 que sea apta. 

    Al crear un grupo de Microsoft 365, Outlook crea automáticamente una bandeja de entrada de Outlook compartida, un calendario compartido y una biblioteca de documentos para colaborar en archivos. También puede crear un equipo de Microsoft e integrar tareas con Planner en Teams.

    No es necesario que se preocupe de asignar permisos de forma manual a todos esos recursos, ya que, al agregar los miembros al grupo de forma automática, se les conceden los permisos que necesitan para las herramientas que el grupo proporcione.

    Un grupo de Microsoft 365 incluye pertenencia compartida en las siguientes plataformas:

    Buzón compartido: para conversaciones de correo electrónico entre los miembros. Esta bandeja de entrada tiene una dirección de correo electrónico y se puede fijar para aceptar los mensajes de usuarios fuera del grupo e incluso fuera de su organización, de forma muy parecida a una lista de distribución tradicional. Para obtener más información, consulta Enviar un correo electrónico a un grupo en Outlook.

    Calendario compartido: para programar eventos relacionados con el grupo. Para obtener más información, vea Usar un calendario de grupo en Outlook para programar y editar eventos.

    Biblioteca de documentos de SharePoint: un lugar fundamental para el grupo en el que almacenar y compartir archivos. Para obtener más información, consulte Compartir archivos con un grupo en Outlook.

    Bloc de notas de OneNote compartido: para recopilar ideas, investigaciones e información. Para obtener más información, vea OneNote: Introducción.

    Sitio de grupo de SharePoint: un repositorio central de información, vínculos y contenido relacionado con el grupo. Para obtener más información, consulta SharePoint.

    Planner: para asignar y administrar tareas de proyecto entre los miembros del grupo. Para obtener más información, consulta Introducción a Microsoft Planner.

    Acceda a su grupo en Outlook desde cualquier lugar

    Al crear un grupo de Microsoft 365 con una cuenta profesional o educativa, los miembros del grupo pueden interactuar con ella en la aplicación móvil de Outlook.
