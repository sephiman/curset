# Informática básica: conceptos fundamentales sobre el hardware y el software. Sistemas de almacenamiento de datos. Sistemas operativos. Nociones básicas de seguridad informática.

Conceptos de informática básica que preguntan los exámenes, con las etiquetas de Windows 11 en español de España.

## Conceptos fundamentales sobre el hardware y el software

- **Procesador (CPU)**: la «unidad de procesamiento central» es el «cerebro» principal del equipo; los demás chips se
  conectan a una placa de circuito, la placa base (fuente: `ms-learn-equipos-procesador.html`). Puede interpretar una
  secuencia de instrucciones (fuente: `ms-win32-processor-cache.html`) y el sistema operativo lo usa para ejecutar
  instrucciones de programa (fuente: `ms-win-analisis-cpu.html`).
- **Memoria RAM**: la memoria de acceso aleatorio guarda temporalmente los datos que la CPU usa; lo que está en la RAM
  desaparece al apagar el equipo (fuente: `ms-learn-equipos-ram.html`, `ms-learn-equipos-almacenamiento.html`).
- **Memoria caché**: la caché de nivel 2 o 3 del procesador tiene un tiempo de acceso más rápido que la RAM principal
  (fuente: `ms-win32-processor-cache.html`).
- **Bit y byte**: un bit tiene dos valores, 1 o 0; un byte es una secuencia de 8 bits (fuente: `ms-sql-bits.html`).
- **Múltiplos del byte**: 1 MB = 10^6 B y 1 GB = 10^9 B; kilo = 10^3, mega = (10^3)^2, giga = (10^3)^3,
  tera = (10^3)^4, peta = (10^3)^5, exa = (10^3)^6. El prefijo binario gibi vale 2^30: 1 GiB = 2^30 B (fuente:
  `nist-prefijos-binarios.html`).
- **Requisitos de Windows 11**: procesador de 1 GHz o más con 2 o más núcleos, 4 GB de RAM, 64 GB de almacenamiento,
  firmware UEFI compatible con el arranque seguro, TPM 2.0 y tarjeta gráfica compatible con DirectX 12 o posterior con
  controlador WDDM 2.0 (fuente: `ms-win11-requisitos.html`).
- **BIOS y UEFI**: la interfaz del firmware controla el arranque y después pasa el control a Windows; UEFI reemplaza a
  la antigua interfaz de firmware del BIOS (fuente: `ms-win-uefi.html`).
- **Plug and Play (PnP)**: parte de Windows que permite agregar y quitar dispositivos sin configuración manual; reconoce
  el hardware y carga los controladores adecuados (fuente: `ms-win-plug-and-play.html`).
- **Dispositivos de entrada**: el teclado y los dispositivos señaladores (pantalla táctil, ratón, lápiz óptico y panel
  táctil) (fuente: `ms-win-dispositivos-entrada.html`).
- **Router**: distribuye tráfico de red entre dos o más redes diferentes (fuente: `incibe-glosario-ciberseguridad.pdf`).
- **Aplicación de fuentes abiertas**: se distribuye con una licencia que permite ejecutarla, conocer el código fuente,
  modificarla o mejorarla y redistribuir copias (fuente: `boe-rd-4-2010-eni.pdf`).
- **Aplicaciones de Office**: PowerPoint y Excel, entre otras (fuente: `ms-office-autoguardado.html`).
- **SaaS** (*Software as a Service*): el software y sus datos se alojan en servidores de un tercero y el cliente accede
  por Internet (fuente: `incibe-glosario-ciberseguridad.pdf`).
- **Escritorio virtual (VDI)**: escritorios virtuales hospedados en servidores centralizados, accesibles desde casi
  cualquier dispositivo (fuente: `azure-vdi.html`).
- **Sistema gestor de bases de datos**: Microsoft SQL Server es un sistema de administración de bases de datos
  relacionales (RDBMS) (fuente: `ms-sql-server.html`). MySQL es un motor de base de datos (fuente:
  `ms-azure-mysql.html`).
- **Minería de datos**: proceso de detectar información accionable de grandes conjuntos de datos; usa análisis
  matemáticos para derivar patrones y tendencias (fuente: `ms-mineria-datos.html`).

## Sistemas de almacenamiento de datos

- **Disco duro (HDD) y unidad de estado sólido (SSD)**: conservan los datos sin energía; el HDD usa discos que giran y
  la SSD no tiene partes móviles (fuente: `ms-learn-equipos-almacenamiento.html`).
- **NTFS**: sistema de archivos predeterminado de Windows; permisos por listas de control de acceso (ACL) y cifrado con
  BitLocker (fuente: `ms-win-ntfs.html`).
- **Sistemas de archivos de Windows**: los cuatro principales son NTFS, exFAT, UDF y FAT32; solo NTFS cifra a nivel de
  sistema de archivos (fuente: `ms-win-sistemas-archivos.html`).
- **RAID**: en Espacios de almacenamiento directo (Windows Server), la creación de reflejo mantiene varias copias y se
  parece a RAID-1; la paridad única se parece a RAID-5 (fuente: `ms-win-tolerancia-errores.html`).
- **Almacenamiento en la nube**: guarda los datos en servidores remotos accesibles por Internet, no en hardware local
  (fuente: `azure-almacenamiento-nube.html`).
- **Copias de seguridad de Windows**: «Configuración › Cuentas › Copias de seguridad de Windows»; copia en OneDrive las
  carpetas Escritorio, Documentos, Imágenes, Vídeos y Música. La cuenta de Microsoft gratuita trae 5 GB de OneDrive
  (fuente: `ms-win-copias-seguridad.html`).

## Sistemas operativos

- **Ejemplos**: Windows (fuente: `ms-win-componentes-kernel.html`) y macOS, el sistema operativo del Mac (fuente:
  `apple-macos.html`).
- **Funciones del kernel de Windows**: el administrador de memoria administra la memoria física; el de procesos y
  subprocesos controla la ejecución de los subprocesos; el de E/S comunica las aplicaciones con los controladores de
  dispositivo (fuente: `ms-win-componentes-kernel.html`).

## Nociones básicas de seguridad informática

- **Malware**: software que busca dañar o infiltrarse en un sistema de información sin el consentimiento de su
  propietario; incluye virus, gusanos, troyanos y spyware (fuente: `incibe-glosario-ciberseguridad.pdf`).
- **Virus, gusano y troyano**: el virus infecta ficheros ejecutables o sectores de arranque; el gusano se copia y se
  propaga solo por la red; el troyano suele crear una puerta trasera (fuente: `incibe-glosario-ciberseguridad.pdf`).
- **Antivirus**: evita que se ejecute software malicioso en el equipo (fuente: `incibe-glosario-ciberseguridad.pdf`). El
  de Windows está en «Seguridad de Windows › Protección contra virus y amenazas» (fuente: `ms-win-antivirus.html`).
- **Cortafuegos (firewall)**: programas o dispositivos en los límites de una red que permiten y limitan el tráfico según
  unas normas (fuente: `incibe-glosario-ciberseguridad.pdf`). En Windows: «Seguridad de Windows › Firewall y protección
  de red», con perfiles de dominio, privada y pública (fuente: `ms-win-firewall.html`).
- **Phishing**: alguien suplanta a una entidad por correo o mensaje instantáneo para conseguir credenciales o datos de
  la tarjeta (fuente: `incibe-glosario-ciberseguridad.pdf`).
- **CAPTCHA**: prueba desafío-respuesta que determina si el usuario es un humano o un bot (fuente:
  `incibe-glosario-ciberseguridad.pdf`).
- **Certificado digital**: fichero generado por una Autoridad Certificadora (CA) que asocia unos datos de identidad a
  una persona física, organismo o empresa (fuente: `incibe-glosario-ciberseguridad.pdf`).
- **Contraseña robusta**: larga, creada al azar o combinando mayúsculas, minúsculas, números y caracteres especiales; un
  gestor de contraseñas las genera y las guarda cifradas (fuente: `incibe-glosario-ciberseguridad.pdf`).
- **Autenticación multifactor**: pide un segundo factor además de usuario y contraseña: algo que sabes, algo que tienes
  o algo que eres (fuente: `ms-cuenta-mfa.html`).
- **Actualizaciones**: corrigen fallos de seguridad y errores (fuente: `incibe-glosario-ciberseguridad.pdf`). «Inicio ›
  Configuración › Windows Update»; Windows 11 las instala automáticamente y «Pausar actualizaciones» solo las detiene un
  tiempo (fuente: `ms-win-update.html`).
- **Esquema Nacional de Seguridad (ENS)**: RD 311/2022, para todo el sector público. Exige copias de seguridad
  (art. 26 ENS) y doble factor de autenticación para acceder desde zonas no controladas como Internet (anexo II,
  op.acc.6, ENS) (fuente: `BOE-A-2022-7191_ens_2024-11-06.pdf`).

## Lo que más cae

- 1 GB son 10^9 bytes y 1 MB son 10^6 bytes; por encima del terabyte van el petabyte y el exabyte (fuente:
  `nist-prefijos-binarios.html`).
- La RAM guarda temporalmente los datos que usa la CPU (fuente: `ms-learn-equipos-ram.html`).
- El procesador interpreta instrucciones y con él se ejecutan las de los programas (fuente:
  `ms-win32-processor-cache.html`, `ms-win-analisis-cpu.html`).
- El ratón y el lápiz óptico son dispositivos de entrada (fuente: `ms-win-dispositivos-entrada.html`).
- NTFS es el sistema de archivos predeterminado de Windows (fuente: `ms-win-ntfs.html`).
- La caché del procesador es más rápida que la RAM principal (fuente: `ms-win32-processor-cache.html`).
- El antivirus evita que se ejecute software malicioso (fuente: `incibe-glosario-ciberseguridad.pdf`).
- Gusanos y troyanos son malware; el gusano se propaga solo por la red (fuente: `incibe-glosario-ciberseguridad.pdf`).
- Administrar la memoria física es una función del sistema operativo (fuente: `ms-win-componentes-kernel.html`).
- En el modelo SaaS el software se aloja en servidores de un tercero y se usa por Internet (fuente:
  `incibe-glosario-ciberseguridad.pdf`).
