# Scope audit C2 R2b, part A — bloque II temas 1–12 (m02-l01 … m02-l12)

Date 2026-11-06. Read-only audit under `scope/spec.md`. Programme: `content/age-auxiliar-c2/sources/programa.md`
(«Anexo I — 3. Programa», bloque «II. Actividad administrativa y ofimática»). Lessons:
`content/age-auxiliar-c2/es/lessons/`. Exam evidence: the parsed questionnaires
`docs/age-verification/c2/r0a/parsed/*_cuestionario.json`, keys in `docs/age-verification/c2/r0a/keys/`, tema and
estado from `docs/age-c2-official-exams-ledger.md`. Exam references are `exam | part | nº` with the ledger's names
(conv2025_A, conv2024_A, conv2024_X, conv2022, conv2020, conv2020_X). Modelo B is not counted. conv2020 and
conv2020_X are the OEP 2020 exams, «programa anterior»: they count as evidence for keeping a section and are marked
«(OEP 2020, programa anterior)» wherever they are cited. For temas II.5–II.12 (ofimática) a sentence maps to the
feature set it names; `docs/age-c2-ofimatica-index.md` is the course's coverage map for them.

Sections exclude the fixed blocks «Lo que más cae», «Normativa» and «Fuentes».
