./Device/Vendor/MSFT/Policy/Config/ADMX_WindowsExplorer/CheckSameSourceAndTargetForFRAndDFS

Esta configuración de directiva permite evitar la pérdida de datos al cambiar la ubicación de destino del redireccionamiento de carpetas y los destinos nuevos y antiguos apuntan al mismo recurso compartido de red, pero tienen rutas de acceso de red diferentes.

  • Si habilita esta configuración de directiva, redirección de carpetas crea un archivo temporal en la ubicación anterior para comprobar que las ubicaciones nuevas y antiguas apuntan al mismo recurso compartido de red. Si las ubicaciones nuevas y antiguas apuntan al mismo recurso compartido, la ruta de acceso de destino se actualiza y los archivos no se copian ni eliminan. Se elimina el archivo temporal.

  • Si deshabilita o no configura esta configuración de directiva, redirección de carpetas no crea un archivo temporal y funciones como si las ubicaciones nuevas y antiguas apuntara a recursos compartidos diferentes cuando sus rutas de acceso de red son diferentes.

Nota

Si las rutas de acceso apuntan a recursos compartidos de red diferentes, esta configuración de directiva no es necesaria. Si las rutas de acceso apuntan al mismo recurso compartido de red, los datos contenidos en las carpetas redirigidas se eliminan si esta configuración de directiva no está habilitada.

Esta configuración permite que un administrador revierta el comportamiento específico de Windows Shell al comportamiento de Shell clásico.

  • Si habilita esta opción, los usuarios no pueden configurar su sistema para abrir elementos haciendo clic con un solo clic (por ejemplo, en Mouse en Panel de control). Como resultado, la interfaz de usuario se parece a la interfaz de Windows NT 4.0 y los usuarios no pueden restaurar las nuevas características.

Al habilitar esta directiva, también se desactivará el panel de vista previa y se establecerán las opciones de carpeta de Explorador de archivos para usar la vista De carpetas clásicas y se deshabilitará la capacidad de los usuarios para cambiar estas opciones.

  • Si deshabilita o no configura esta directiva, el comportamiento de Explorador de archivos predeterminado se aplica al usuario.

Nota

En sistemas operativos anteriores a Windows Vista, habilitar esta directiva también deshabilitará la vista Active Desktop y Web. Esta configuración también tendrá prioridad sobre la opción "Habilitar Active Desktop". Si ambas directivas están habilitadas, Active Desktop está deshabilitado.

Además, vea la opción "Deshabilitar Active Desktop" en Configuración de usuario\Plantillas administrativas\Escritorio\Escritorio activo y la opción "No permitir que las opciones de carpeta se abran desde el botón Opciones de la pestaña Ver de la cinta de opciones" en Configuración del usuario\Plantillas administrativas\Componentes de Windows\Explorador de archivos.

Nota

Esta advertencia se presenta como un cuadro de diálogo intersticial que se muestra antes de ejecutar una aplicación que se ha descargado de Internet y que no se reconoce o se sabe que es malintencionada. No se muestra ningún cuadro de diálogo para las aplicaciones que no parecen sospechosas.

Se envía información a Microsoft sobre los archivos y programas que se ejecutan en equipos con esta característica habilitada.

  • Si habilita esta directiva, SmartScreen se activará para todos los usuarios. Su comportamiento se puede controlar mediante las siguientes opciones:

  • Advertir y evitar la omisión

  • Advertir.

  • Si habilita esta directiva con la opción "Advertir y evitar la omisión", los diálogos de SmartScreen no presentarán al usuario la opción de omitir la advertencia y ejecutar la aplicación. SmartScreen seguirá mostrando la advertencia en los intentos posteriores de ejecutar la aplicación.

  • Si habilita esta directiva con la opción "Advertir", los cuadros de diálogo de SmartScreen advertirán al usuario de que la aplicación parece sospechosa, pero permitirá al usuario ignorar la advertencia y ejecutar la aplicación de todos modos. SmartScreen no volverá a advertir al usuario de esa aplicación si el usuario indica a SmartScreen que ejecute la aplicación.

  • Si deshabilita esta directiva, SmartScreen se desactivará para todos los usuarios. No se advertirá a los usuarios si intentan ejecutar aplicaciones sospechosas desde Internet.

  • Si no configura esta directiva, SmartScreen se habilitará de forma predeterminada, pero los usuarios pueden cambiar su configuración.

Para obtener más información, vea Microsoft Defender SmartScreen.

Normalmente son los mismos, pero un origen puede definir una ubicación específica de una miniatura que sea diferente de la ubicación del elemento.

  • Si habilita esta configuración de directiva, los usuarios pueden obtener una vista previa de los elementos y obtener miniaturas personalizadas de los resultados de la consulta de OpenSearch en esta zona mediante Explorador de archivos.

Los archivos de acceso directo suelen incluir una ruta de acceso absoluta al archivo de destino original, así como la ruta de acceso relativa al archivo de destino actual. Cuando el sistema no encuentra el archivo en la ruta de acceso de destino actual, busca de forma predeterminada el destino en la ruta de acceso original. Si el acceso directo se ha copiado en otro equipo, la ruta de acceso original podría conducir a un equipo de red, incluidos los recursos externos, como un servidor de Internet.

  • Si habilita esta configuración de directiva, Windows solo busca en la ruta de acceso de destino actual. No busca la ruta de acceso original aunque no pueda encontrar el archivo de destino en la ruta de acceso de destino actual.

  • Si deshabilita o no establece esta configuración de directiva, Windows busca la ruta de acceso original cuando no encuentra el archivo de destino en la ruta de acceso de destino actual.

  • Si habilita esta configuración de directiva, las bibliotecas o los conectores de búsqueda especificados aparecerán en los vínculos "Buscar de nuevo" y en los vínculos del menú Inicio.

  • Si deshabilita o no establece esta configuración de directiva, no aparecerán bibliotecas ni conectores de búsqueda en los vínculos "Buscar de nuevo" o en los vínculos del menú Inicio.
