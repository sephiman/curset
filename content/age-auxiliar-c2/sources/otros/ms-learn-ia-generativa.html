Cómo funcionan los LLM y la inteligencia artificial generativa

En este artículo

La inteligencia artificial generativa es un tipo de inteligencia artificial que puede crear contenido original, como lenguaje natural, imágenes, audio y código. La salida depende de las entradas que proporcione. Los usuarios suelen interactuar con la inteligencia artificial generativa a través de aplicaciones de chat que usan lenguaje natural como entrada. ChatGPT, desarrollado por OpenAI, es un ejemplo popular. Las aplicaciones de IA generativas que usan lenguaje natural como entrada están basadas en modelos de lenguaje grande (LLM) para realizar el procesamiento de lenguaje natural (NLP).

Cómo funciona la IA generativa

Toda la inteligencia artificial generativa se basa en modelos. Estos modelos se entrenan con grandes conjuntos de datos en forma de contenido, como lenguaje natural, imágenes, audio y código. Los modelos de IA generativa usan los patrones identificados en los datos de entrenamiento para generar contenido nuevo y estadísticamente similar.

El modelo de IA usa la entrada para crear una salida. El modelo analiza primero la entrada en un formulario que puede comprender. A continuación, el modelo usa esos datos para identificar patrones coincidentes de su entrenamiento que combina para compilar la salida final. Los modelos de IA generativa están diseñados para generar contenido único, por lo que no generarán la misma salida para entradas idénticas.

Las aplicaciones de IA generativas que admiten lenguaje natural como entrada o salida usan LLM para hacerlo. LLM realiza PNL, que clasifica el texto de entrada y determina su sentimiento. El modelo de IA generativa usa esa clasificación y análisis de sentimiento para identificar patrones y crear la salida. Si la salida es texto, LLM lo genera por sí solo. Si la salida es audio o imágenes, los modelos adicionales proporcionan los datos y patrones para generar salidas en ese formato.

Usos comunes de IA generativa

Las aplicaciones de inteligencia artificial generativa admiten una variedad de casos de uso y salidas, que se describen en las secciones siguientes.

Generación de lenguaje natural

Algunas aplicaciones de IA generativas pueden producir salidas de lenguaje natural, como:

  • Resúmenes con palabras profesionales para un perfil de LinkedIn
  • Descripciones enriquecidas de elementos en un escaparate en línea
  • Ideas para comidas saludables

Generación de imágenes

Algunas aplicaciones de IA genera salidas de imagen a partir de entradas de lenguaje natural. En función de la aplicación y sus modelos, es posible que los usuarios puedan especificar:

  • Las personas o las cosas que se van a aparecer en la imagen
  • Estilo artístico en el que crear la imagen
  • Referencias para generar imágenes similares

La generación de imágenes puede crear avatares virtuales para cuentas en línea, logotipos de diseño para un negocio o proporcionar inspiración artística para creadores. Generación de audio

Algunas aplicaciones de IA genera salidas de audio a partir de entradas de lenguaje natural. En función de la aplicación y sus modelos, es posible que los usuarios puedan:

  • Síntesis de voces de sonido natural a partir de texto de entrada
  • Crear música en un estilo específico o con ciertos instrumentos
  • Modificación de archivos de audio de entrada en función de los criterios establecidos proporcionados en lenguaje natural

La generación de audio puede proporcionar respuestas habladas de asistentes de voz digital, agregar instrumentos de respaldo a canciones para producción musical o reproducir la voz original de un usuario a partir de grabaciones de referencia.

Generación de código

Algunas aplicaciones de IA genera código a partir de entradas de lenguaje natural. En función de la aplicación y sus modelos, es posible que los usuarios puedan generar código que:

  • Está en el idioma de su elección
  • Acepta una estructura de entrada y salida específica
  • Usa tecnologías específicas basadas en su documentación de referencia

La generación de código puede proporcionar implementaciones rápidas de operaciones comunes, como ordenar o filtrar datos, acelerar la traducción de código de un lenguaje a otro, o responder preguntas sobre una tecnología basada en la documentación de referencia especificada. Cómo funcionan los LLM

Al entrenar un LLM, el texto de entrenamiento se divide primero en tokens. Cada token identifica un valor de texto único. Un token puede ser una palabra distinta, una palabra parcial o una combinación de palabras y signos de puntuación. A cada token se le asigna un identificador, que permite que el texto se represente como una secuencia de identificadores de token.

Después de dividir el texto en tokens, se asigna un vector contextual, conocido como inserción, a cada token. Estos vectores de inserción son datos numéricos con varios valores, donde cada elemento del vector de un token representa un atributo semántico del token. Los elementos del vector de un token se determinan en función de la frecuencia de uso de los tokens juntos o en contextos similares.

El objetivo es predecir el siguiente token de la secuencia en función de los tokens anteriores. El modelo asigna un peso a cada token de la secuencia existente, que representa su influencia relativa en el siguiente token. A continuación, el modelo usa los pesos de los tokens anteriores e incrustaciones para calcular y predecir el siguiente valor vectorial. A continuación, el modelo selecciona el token más probable para continuar la secuencia en función del vector previsto.

Este proceso continúa iterativamente para cada token de la secuencia, con la secuencia de salida que se usa de forma regresiva como entrada para la siguiente iteración. La salida se crea un token a la vez. Esta estrategia es análoga a cómo funciona autocompletar, donde las sugerencias se basan en lo que se ha escrito hasta ahora y se actualizan con cada entrada nueva.

Durante el entrenamiento, el modelo conoce la secuencia de tokens completa, pero omite todos los tokens después del que se está considerando actualmente. El modelo compara el valor vectorial previsto con el valor real y calcula la pérdida. Después, el entrenamiento ajusta incrementalmente los pesos para reducir la pérdida y mejorar el modelo.
