## m02-l11-q004
¿Cuál de las siguientes describe la forma de una dirección de correo electrónico de Internet según el RFC 5322?
- a) El nombre del destinatario entre paréntesis, el signo @ y un dominio.
- b) Una cadena que se interpreta localmente, un punto y un dominio de Internet.
- c) Un dominio de Internet, el signo @ y una cadena que se interpreta localmente.
- d) Una cadena que se interpreta localmente, el signo @ y después un dominio de Internet.  ✓
Cita: fuente: `rfc5322-formato-mensaje.txt`; «3.4.1. Addr-Spec Specification»
Explicación: El RFC 5322 define la dirección como una cadena interpretada localmente, seguida del signo @ y de un dominio de Internet. ## m02-l11-q005
Según el RFC 5322, ¿qué identifica la parte de una dirección de correo electrónico que va detrás del signo @?
- a) El nombre de un buzón concreto, que se interpreta en el host de destino.
- b) El punto al que se entrega el correo, por ejemplo un nombre de dominio de Internet.  ✓
- c) El grupo de destinatarios al que pertenece el buzón, sin sus direcciones.
- d) El nombre para mostrar del destinatario, que ve el usuario del programa.
Cita: fuente: `rfc5322-formato-mensaje.txt`; «The domain portion identifies the point to which the mail is delivered.»
Explicación: El RFC dice que la parte del dominio identifica el punto al que se entrega el correo; en la forma de átomos con puntos se interpreta como un nombre de dominio de Internet. El nombre de un buzón interpretado en el host es la parte local, la que va delante del @. El nombre para mostrar es opcional y va fuera de la dirección. El grupo es otra construcción del RFC, un nombre seguido de una lista de buzones.
