## Notes

- Kind. The spec assigns `plazos` to the budget cycle; the writer used `tabla`. That is the right call: `plazos` claims
  an order, and the rows include two norms for the same act (134.4 CE and 38 LGP side by side, as the rule for two
  norms asks) and a non-step fact (ejercicio = año natural). The header «Paso» is only a label and does not number
  the rows. The order of rows 1→2 does not hold as a sequence anyway (134.3 CE and 37.1 LGP are two plazos for the same
  presentación, not two steps).
- The «Qué es cada modificación» rows follow the order of the art. 51 list (a–e). That list is complete, so the
  table does not read as selective. Crédito extraordinario/suplemento is labelled «del Estado»; the organismo autónomo
  regime (art. 56) is in the prose table l. 201–207 and is rightly not mixed in.
- Repetition. No row only repeats a prose list or table. The arbol restates prose l. 24 and l. 40–52 in tree form but
  not the capítulos table (l. 54–59). The modificaciones tabla overlaps two cells of the «Quién autoriza y cómo se
  financia» table (l. 177–178: «Los ingresos que la originan (art. 53.1 LGP)», «El traspaso de dotaciones entre
  créditos (art. 52.1 LGP)»), but its column is the definition, which that table does not give.
- If m05-l02 row 6 is removed, row 5 («en los casos del artículo 58») stays correct as a statement of art. 58, and the
  suspension of letter b) is still in the prose right above it (l. 325–327). The by-reference alternative keeps the
  table aligned with the presupuesto in force without adding a fact. The writer chooses which one.
- The same MRR shortening in the prose (l. 325–327) is an R2 prose matter. The reviewer did not edit it. It is listed
  above so that the ledger can carry it.
- Citations «art. 38.1–2 LGP» and «art. 54.1–2 LGP» use a range; each one names a single norm, so they fall within the
  parser limit noted in the spec. Whether the range form resolves to a source link was not tested here.
