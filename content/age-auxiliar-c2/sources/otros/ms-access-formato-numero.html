    Aplicar formato a un campo de moneda o número

    Se aplica a
    Access para Microsoft 365 Access 2024 Access 2021 Access 2019 Access 2016
    Obtener ayuda con Copilot
    Ayúdame a dar formato a un campo de número o moneda. Muéstrame cómo dar formato a una función. ¿Cómo puedo aplicar un formato personalizado?

    Los tipos de datos Número, Número grande y Moneda de Access incluyen muchos formatos. Para el formato de números y monedas, tiene tres opciones: mantener los formatos predeterminados, aplicar un formato predefinido o crear un formato personalizado. Al aplicar un formato a un campo de tabla, Access aplica automáticamente el mismo formato a cualquier control de formulario o informe que luego enlace a ese campo de tabla. El formato solo cambia la forma en que se muestran los datos. No afecta a cómo se almacenan los datos ni cómo los usuarios escriben datos.

    Información general sobre los formatos de número y moneda

    Para crear un formato personalizado, escriba varios caracteres en la propiedad Formato de un campo de tabla. Los caracteres pueden ser marcadores de posición, como 0 y #; separadores, como puntos y comas, caracteres literales y colores, en función de cómo desee que aparezca el formato. Access aplica automáticamente cualquier formato personalizado que use en un campo de tabla a un control dependiente de un formulario o informe.

    Puede especificar formatos para cuatro tipos de valores numéricos: positivo, negativo, cero (0) y nulo (sin definir). Si crea un formato para cada tipo de valor, coloque primero el formato de los valores positivos, en segundo lugar el formato de los valores negativos, en tercer lugar el formato de los valores cero y al final el formato de los valores nulos. Separe cada formato con un punto y coma.

    Ejemplo de formato personalizado: #,###.##;(#,###.##)[Red];0,000.00;"Undefined"

    Se muestra como:

    • 1,234.568
    • (1,234.568) en rojo
    • 0,000.00
    • Undefined

    Esto es lo que significa el formato:

    • El signo de número (#) es un marcador de posición para dígitos. Si no hay valores, Access muestra un espacio en blanco. Para mostrar ceros en lugar de espacios en blanco, úselo 0 como marcador de posición. Por ejemplo, para que se muestre 1234 como 1234.00, use la cadena ####.00de formato .
    • Los valores positivos se muestran con dos decimales.
    • Los valores negativos se muestran con dos decimales, entre paréntesis y en rojo.
    • Los valores cero se muestran como el número 0, siempre con dos decimales.
    • Los valores nulos se muestran como la palabra Undefined.

    Son posibles hasta cuatro secciones para una cadena, y cada sección está separada por un punto y coma (;). Si el campo de la tabla acepta valores nulos, puede omitir la cuarta sección.

    Sección Formato Descripción Ejemplo
    Si la primera sección contiene #,###.## Muestra valores positivos. 1234.5678 Se muestra como 1,234.568. Este formato usa la coma como separador de miles y el punto como separador decimal. Si los valores decimales del registro superan el número de caracteres de marcador de posición en el formato personalizado, Access redondea los valores y muestra solo el número de valores especificado por el formato. Por ejemplo, si el campo contiene 3,456.789, pero su formato especifica dos posiciones decimales, Access redondea el valor decimal a 0.79. Propina: Para un formato con valores más grandes o más posiciones decimales, agregue más marcadores de posición para el valor decimal, como #,###.###.
    Si la segunda sección contiene (#,###.##)[Red] Muestra solo valores negativos. Si los datos no contienen valores negativos, Access deja el campo en blanco. El valor negativo se escribe entre literales o paréntesis. En este ejemplo, cualquier valor negativo se muestra en rojo.
    Si la tercera sección contiene 0,000.00 Define el formato de todos los valores cero (0). cuando el campo contiene un valor de cero, 0,000.00 se muestra. Para mostrar texto en lugar de un número, use "Zero" entre comillas dobles.
    Si la cuarta sección contiene "Undefined" Define lo que ven los usuarios cuando un registro contiene un valor nulo. En este caso, los usuarios ven la palabra Undefined. También puede usar otro texto, como "Null" o "****". Los caracteres entre comillas dobles se tratan como literales y se muestran exactamente como se han escrito.

    Principio de página

    Aplicar un formato predefinido

    Access proporciona varios formatos predefinidos para datos de números y monedas. El formato predeterminado es mostrar el número tal como se ha introducido.

    Recomendación

    Puede usar la propiedad DecimalPlaces para reemplazar el número predeterminado de posiciones decimales para el formato predefinido que especifique para la propiedad Format .

    En una tabla

    1. Abra la tabla en la Vista Diseño.
    2. En la sección superior de la cuadrícula de diseño, seleccione el campo de fecha y hora al que desea aplicar formato.
    3. En la sección Propiedades de campo de la sección inferior, haga clic en la flecha del cuadro de propiedades Formato y seleccione un formato de la lista desplegable.
    4. Después de seleccionar un formato, aparece el botón Opciones de actualización de propiedades . Permite aplicar el nuevo formato a cualquier otro campo de tabla y control de formulario que lógicamente lo heredaría. Para aplicar los cambios en la base de datos, haga clic en la etiqueta inteligente y, a continuación, haga clic en Actualizar formato en todos los lugares donde <se use el nombre> de campo. En este caso, Nombre de campo es el nombre de su número o campo de moneda.
    5. Para aplicar los cambios a toda la base de datos, haga clic en Sí cuando aparezca el cuadro de diálogo Propiedades de actualización y se muestren los formularios y otros objetos que heredarán el nuevo formato. Para obtener más información, vea Propagar una propiedad de campo.
    6. Guarde los cambios y cambie a la vista Hoja de datos para ver si el formato satisface sus necesidades.

    Nota

    Los nuevos formularios, informes o vistas que cree basados en esta tabla obtienen el formato de la tabla, pero puede invalidarlo en el formulario, informe o vista sin cambiar el formato de la tabla.

    En un formulario o informe

    En un formulario o informe, las fechas suelen mostrarse en cuadros de texto. Simplemente establezca la propiedad Formato del cuadro de texto en el formato de fecha que desee.

    1. Abra la vista Presentación o la vista Diseño del formulario o del informe.
    2. Coloque el puntero en el cuadro de texto con el número o la moneda.
    3. Presione F4 para mostrar la hoja de propiedades.
    4. Establezca la propiedad Formato en uno de los formatos de fecha predefinidos.

    En una consulta

    1. Abra la consulta en la vista Diseño.
    2. Haga clic con el botón derecho en el campo de fecha y, después, haga clic en Propiedades.
    3. En la hoja de propiedades, seleccione el formato que desee en la lista de propiedades Formato .

    En una expresión

    • Use la FormatDateTime función para aplicar formato a un valor de fecha a uno de varios formatos predefinidos. Esto puede resultarle útil si está trabajando en un área que requiere una expresión, como una macro o una consulta.

    Principio de página

    Aplicar un formato personalizado

    1. Abra la tabla en la Vista Diseño.

    2. En la sección superior de la cuadrícula de diseño, seleccione el campo de fecha y hora al que desea aplicar formato.

    3. En la sección Propiedades de campo , seleccione la pestaña General , haga clic en la celda situada junto al cuadro Formato e introduzca los caracteres específicos según sus necesidades de formato.

    4. Después de seleccionar un formato, aparece la etiqueta inteligente Opciones de actualización de propiedades . Permite aplicar el nuevo formato a cualquier otro campo de tabla y control de formulario que lógicamente lo heredaría. Para aplicar los cambios en la base de datos, haga clic en la etiqueta inteligente y, a continuación, haga clic en Actualizar formato en todos los lugares donde se use el nombre de campo. En este caso, Nombre de campo es el nombre del campo de fecha y hora.

    5. Para aplicar los cambios a toda la base de datos, haga clic en Sí cuando aparezca el cuadro de diálogo Propiedades de actualización y se muestren los formularios y otros objetos que heredarán el nuevo formato. Para obtener más información, vea Propagar una propiedad de campo.

    6. Guarde los cambios y cambie a la vista Hoja de datos para ver si el formato satisface sus necesidades.

    7. Pruebe el formato haciendo lo siguiente:

      • Escriba valores sin separadores de miles ni separadores decimales y vea cómo el formato trata los datos. ¿El formato coloca los separadores en los lugares correctos?
      • Escriba valores que sean más largos o más cortos de lo previsto (con y sin separadores) y vea cómo se comporta el formato. ¿El formato agrega espacios en blanco no deseados o ceros iniciales o finales?
      • Escriba un valor cero o nulo en un formato destinado a valores positivos o negativos y vea si le gusta el resultado.

    Nota

    Cuando aplica un formato a un campo de tabla, Access usa el mismo formato en cualquier control de formulario o informe que enlace a ese campo.

    Ejemplos de formatos personalizados

    A continuación se muestran ejemplos de formatos de número personalizados.

    Opción Descripción
    0;(0);;"Null" Muestra valores positivos normalmente, los valores negativos entre paréntesis y la palabra Null si el valor es nulo.
    +0.0;–0.0;0.0 Muestra un signo más (+) o menos (–) con números positivos o negativos y muestra 0.0 si el valor es cero.

    Principio de página

    Caracteres de formato personalizado

    Para crear un formato personalizado, use los siguientes caracteres como marcadores de posición y separadores.

    Carácter Descripción
    # Se usa para mostrar un dígito. Cada instancia del carácter representa una posición para un número. Si no existe ningún valor en una posición, Access muestra un espacio en blanco. También se puede usar como marcador de posición. Por ejemplo, si aplica el formato #,### e introduce un valor de 45 en el campo, 45 se muestra. Si especifica 12,145 un campo, Access se mostrará 12,145 aunque haya definido solo un marcador de posición a la izquierda del separador de miles.
    0 Se usa para mostrar un dígito. Cada instancia del carácter representa una posición para un número. Si no existe ningún valor en una posición, Access muestra un cero (0).
    Separador decimal
    . (punto)    		 Indica dónde quiere que Access coloque el carácter separador entre una parte entera y decimal de un campo de número o de moneda. Los separadores decimales varían y se establecen en la configuración regional de Windows.
    Separador de miles
    , (coma)    		 Indica dónde quiere que Access coloque el carácter separador entre la parte de miles de un número o campo de moneda. Los separadores de miles varían y se establecen en la configuración regional de Windows.
    espacios en blanco, +-$() Se usa para insertar espacios en blanco, caracteres matemáticos (+-) y símbolos financieros (¥£$) según sea necesario en cualquier lugar de las cadenas de formato. Si desea usar otros símbolos matemáticos comunes, como la barra diagonal (\ o /) y el asterisco (*), rodéelos entre comillas dobles. Ten en cuenta que puedes colocarlas en cualquier lugar.
    \ Se usa para forzar a Access a mostrar el carácter que le sigue inmediatamente. Equivale a delimitar un carácter entre comillas dobles.
    ! Se usa para forzar la alineación a la izquierda de todos los valores. Al forzar la alineación a la izquierda, no puede usar los marcadores de # posición y 0 dígitos, pero puede usar marcadores de posición para los caracteres de texto.
    * Se usa para forzar que el carácter inmediatamente posterior al asterisco se convierta en un carácter de relleno, que es un carácter que se usa para rellenar espacios en blanco. Access normalmente muestra los datos numéricos alineados a la derecha y rellena cualquier área a la izquierda del valor con espacios en blanco. Puede agregar caracteres de relleno en cualquier lugar de una cadena de formato y, cuando lo hace, Access rellena los espacios en blanco con el carácter especificado. Por ejemplo, el formato £##*~.00 muestra un importe de moneda como £45~~~~~.15. El número de caracteres de tilde (~) mostrados en el campo depende del número de espacios en blanco en el campo de la tabla.
    % Se usa como último carácter de una cadena de formato. Multiplica el valor por 100 y muestra el resultado con un signo de porcentaje final.
    E+, E-
    - O bien -
    e+, e-    		 Se usa para mostrar valores en notación científica o exponencial. Use esta opción cuando el formato científico predefinido no proporcione suficiente espacio para los valores. Use E+ o e+ para mostrar valores como exponentes positivos y E- o e- para mostrar exponentes negativos. Debe usar estos marcadores de posición con otros caracteres. Por ejemplo, supongamos que aplica el formato 0.000E+00 a un campo numérico y después escribe 612345. Access muestra.6.123E+05 Access primero redondea el número de posiciones decimales a tres, que es el número de ceros a la derecha o a la izquierda del separador decimal. A continuación, Access calcula el valor del exponente a partir del número de dígitos que caen a la derecha o a la izquierda, según la configuración de idioma, del separador decimal del valor original. En este caso, el valor original habría puesto 612345, o cinco dígitos, a la derecha del separador decimal. Por ese motivo, Access muestra 6.123E+05, y el valor resultante es el equivalente de 6.123 x 105.
    "Literal text" Use comillas dobles para rodear el texto que desee que vean los usuarios.
    [color] Se usa para aplicar un color a todos los valores de una sección del formato. Debe escribir el nombre del color entre corchetes y utilizar uno de estos nombres: black, blue, cyan, redyellowgreenmagentao .white

    Principio de página

    Mostrar A.D. o B.C.

    Puede usar un formato personalizado para mostrar A.D. antes o B.C. después de un año, dependiendo de si se introduce un número positivo o negativo. Los números positivos se muestran como años con A.D. antes del año. Los números negativos se muestran como años con B.C. después del año.

    1. Abra la tabla en la Vista Diseño.
    2. En la sección superior de la cuadrícula de diseño, seleccione el campo Número al que desea aplicar formato.
    3. En la sección inferior, haga clic en el cuadro de propiedad Formato y escriba este formato personalizado: "A.D. " #;# " B.C."
