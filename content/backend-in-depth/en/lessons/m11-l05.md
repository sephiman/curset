The snippet below is a worked example written for this lesson, not taken from the page. It searches for the first character that occurs once and is run on four inputs.

```java snippet=m11-l05/EdgeCases.java
import java.util.HashMap;
import java.util.Map;

public class EdgeCases {
    static int firstUnique(String s) {
        Map<Character, Integer> counts = new HashMap<>();
        for (char c : s.toCharArray()) {
            counts.merge(c, 1, Integer::sum);
        }
        for (int i = 0; i < s.length(); i++) {
            if (counts.get(s.charAt(i)) == 1) {
                return i;
            }
        }
        return -1;
    }

    public static void main(String[] args) {
        System.out.println("empty: " + firstUnique(""));
        System.out.println("no unique: " + firstUnique("aabb"));
        System.out.println("swiss: " + firstUnique("swiss"));
        System.out.println("surrogate pair: " + firstUnique("😀😁"));
    }
}
```

The search returns `-1` for the empty string.

The search returns `-1` for `aabb`, where every character repeats.

The search returns `1` for `swiss`, the index of `w`.

For a string of two emoji, `"\uD83D\uDE00\uD83D\uDE01"`, the search returns `1`, an index inside the first surrogate pair, because it compares `char` values.

## Stating complexity
<!-- bullets: 11.5.a -->

:::judgement{source="Amazon Jobs, SDE II interview prep" ref="amazon-sde2-interview-prep#:Rhmt4j6:"}
According to the same page, once a candidate has verified a working solution, the candidate should consider its runtime complexity and how to continue improving upon it.
:::

The snippet counts the steps of two versions of the same search on a string where every character repeats, for n = 100 and n = 200.

```java snippet=m11-l05/StepCounts.java
import java.util.HashMap;
import java.util.Map;

public class StepCounts {
    static int steps;

    static int quadratic(String s) {
        for (int i = 0; i < s.length(); i++) {
            int occurrences = 0;
            for (int j = 0; j < s.length(); j++) {
                steps++;
                if (s.charAt(i) == s.charAt(j)) {
                    occurrences++;
                }
            }
            if (occurrences == 1) {
                return i;
            }
        }
        return -1;
    }

    static int linear(String s) {
        Map<Character, Integer> counts = new HashMap<>();
        for (char c : s.toCharArray()) {
            steps++;
            counts.merge(c, 1, Integer::sum);
        }
        for (int i = 0; i < s.length(); i++) {
            steps++;
            if (counts.get(s.charAt(i)) == 1) {
                return i;
            }
        }
        return -1;
    }

    public static void main(String[] args) {
        for (int n : new int[] {100, 200}) {
            steps = 0;
            quadratic("ab".repeat(n / 2));
            System.out.println("quadratic n=" + n + ": " + steps);
        }
        for (int n : new int[] {100, 200}) {
            steps = 0;
            linear("ab".repeat(n / 2));
            System.out.println("linear n=" + n + ": " + steps);
        }
    }
}
```

The nested-loop version takes 10000 steps for n = 100 and 40000 steps for n = 200.

The `HashMap` version takes 200 steps for n = 100 and 400 steps for n = 200.

## Key points

- The first-unique-character search returns `-1` on an empty string and on `aabb`, and `1` on `swiss`.
- Comparing `char` values makes the search return `1` for two emoji, an index inside a surrogate pair.
- On a string where every character repeats, the nested-loop version takes n squared steps and the `HashMap` version takes 2n.
