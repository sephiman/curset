Acerca de la lectura de disponibilidad general de Azure Vision v3.2

¿Está buscando la versión más reciente de Azure Vision 3.2 en Disponibilidad General? Todas las futuras mejoras de la lectura por OCR forman parte de los dos servicios enumerados anteriormente. No hay más actualizaciones de Azure Vision v3.2. Para más información, consulte Call Azure Vision 3.2 GA Read API y Quickstart: Azure Vision v3.2 GA Read.

El reconocimiento óptico de caracteres o OCR también se conoce como reconocimiento de texto o extracción de texto. Las técnicas de OCR basadas en aprendizaje automático permiten extraer texto impreso o manuscrito de imágenes como pósteres, señales de calle y etiquetas de producto, así como de documentos como artículos, informes, formularios y facturas. El texto se extrae normalmente como palabras, líneas de texto y párrafos o bloques de texto, lo que permite el acceso a la versión digital del texto escaneado. Esta funcionalidad elimina o reduce significativamente la necesidad de entrada manual de datos.

Motor de OCR

El motor de OCR read de Microsoft usa varios modelos avanzados de aprendizaje automático que admiten lenguajes globales. Extrae texto impreso y manuscrito, incluidos idiomas mixtos y estilos de escritura. Puede usar Read como servicio en la nube o como contenedor local para una implementación flexible. También está disponible como una API sincrónica para escenarios de solo imagen y no documentales, con mejoras de rendimiento que simplifican la implementación de experiencias de usuario asistidas por OCR.

¿Cómo se relaciona OCR con el procesamiento inteligente de documentos (IDP)?

Intelligent Document Processing (IDP) usa OCR como tecnología fundamental para extraer la estructura, las relaciones, los valores clave, las entidades y otras conclusiones centradas en documentos con un servicio avanzado de inteligencia artificial basado en aprendizaje automático, como Document Intelligence. Document Intelligence incluye una versión optimizada para documentos de Lectura como motor de OCR mientras se delega a otros modelos para obtener información de gama superior. Si va a extraer texto de documentos digitales y escaneados, use Document Intelligence Read OCR.

Idiomas compatibles con OCR

Ambas versiones de lectura disponibles hoy en Azure Vision admiten varios idiomas para texto impreso y manuscrito. OCR para texto impreso admite inglés, francés, alemán, italiano, portugués, español, chino, japonés, coreano, ruso, árabe, hindi y otros idiomas internacionales que usan scripts latinos, cirílicos, árabes y devanagari. OCR para texto manuscrito admite inglés, chino simplificado, francés, alemán, italiano, japonés, coreano, portugués e idiomas españoles.

Consulte la lista completa de idiomas admitidos por OCR.

Características comunes de OCR

El modelo Read OCR está disponible en Azure Vision y Documento Inteligente con funcionalidades de línea base comunes, mientras optimiza para escenarios respectivos. En la lista siguiente se resumen las características comunes:

  • Extracción de texto impreso y manuscrito en idiomas admitidos
  • Páginas, líneas de texto y palabras con puntuaciones de ubicación y confianza
  • Compatibilidad con idiomas mixtos, modo mixto (impresión y escritura a mano)
  • Disponible como contenedor sin distribución de Docker para la implementación local

Uso de API de Cloud de OCR o implementación local

La mayoría de los clientes prefieren las API en la nube, ya que son fáciles de integrar y ofrecen una productividad rápida. Azure y el servicio Azure Vision controlan las necesidades de escala, rendimiento, seguridad de datos y cumplimiento mientras se centra en satisfacer las necesidades de sus clientes.

Para la implementación local, el contenedor de Lectura de Docker le permite implementar las funcionalidades de OCR disponibles con carácter general de Azure Vision v3.2 en su propio entorno local. Los contenedores son excelentes para requisitos específicos de control de datos y seguridad.

Requisitos de entrada

Read API toma imágenes y documentos como entrada. Las imágenes y documentos deben cumplir los siguientes requisitos:

  • Los formatos de archivo admitidos son JPEG, PNG, BMP, PDF y TIFF.
  • Para los archivos PDF y TIFF, se procesan hasta 2000 páginas (solo las dos primeras páginas para el nivel gratis).
  • El tamaño de archivo de las imágenes debe ser inferior a 500 MB (4 MB para el nivel libre) con dimensiones de al menos 50 x 50 píxeles y como máximo 10 000 x 10 000 píxeles. Los archivos PDF no tienen un límite de tamaño.
  • El alto mínimo del texto que se va a extraer es de 12 píxeles para una imagen de 1024 x 768, que corresponde a aproximadamente un texto de fuente de 8 puntos a 150 PPP.

Nota:

No es necesario recortar una imagen para las líneas de texto. Envíe toda la imagen a Read API y reconozca todos los textos.

Privacidad y seguridad de los datos de OCR

Al igual que con todas las herramientas de Foundry, los desarrolladores que usan el servicio Azure Vision deben tener en cuenta las directivas de Microsoft sobre los datos de los clientes. Consulte la página de herramientas de Foundry en el Centro de confianza de Microsoft para obtener más información.

Pasos siguientes

  • En el caso de OCR con imágenes generales (no de documento), pruebe el inicio rápido de la API REST de Análisis de imágenes de la versión preliminar de Azure Vision 4.0.
  • Para OCR con documentos PDF, Office y HTML, así como imágenes de documento, comience con Lectura Inteligente de Documentos.
  • Para obtener la versión GA anterior, consulte las guías rápidas del SDK GA de Azure Vision 3.2 o la API de REST.
