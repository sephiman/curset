## Misses and flags by cause

**Documentation page: table content not extracted, only the page intro** — misses 146 (m06-l02-q026), 147 (m06-l02-q028),
148 (m06-l02-q029), 149 (m06-l02-q030), 152 (m06-l02-q034). All cite `ms-win-lupa-atajos.html` anchored on the page's intro
sentence «Todos los comandos de teclado para la Lupa de Windows 11, agrupados por tarea.», and the excerpt is that sentence plus
the next one. The facts are rows of the shortcut tables further down the same page (source checked: «Tecla Windows + Esc»,
«Invertir colores … Ctrl+Alt+I», «Vista de lente Ctrl+Alt+L», «Desplazarse a través de las vistas Ctrl+Alt+M», «Alternar entre
el aumento establecido y 1× (normal) Ctrl+Alt+Signo menos (-)»). `excerpt_full` is null. The fix is either to anchor these
citations on the table rows (as item 155 does for Word, which extracts «… — Mayús+TAB» correctly) or to let the extractor
pull the matching table row.

**«Redacción anterior» leaking in unlabeled (future-wording norms)** — flags 141 (m04-l09-q077, art. 173.1 LGSS), 160 (sp-04/q12,
art. 173.1 LGSS), 161 (sp-04/q13, art. 172 LGSS). In all three the fact is in the new (01-12-2026) wording, so the verdict is
yes, but the excerpt ends with the quoted opening of the old wording and «[…]», and `excerpt_full` repeats the old text after
the new one. The «Téngase en cuenta…» note and the «Redacción anterior:» label are dropped while the old text is kept. Same
cause as item 33 of part 00 (art. 19.1 RDL 4/2000).

**Heading not the unit's name** — flag 142 (m06-l01-q371): heading «En este artículo», the page's navigation label; flag 144
(m06-l01-q375): heading is the file name «incibe-glosario-ciberseguridad.pdf».

**Run-together label (minor)** — flags 156 (m06-l04-q403), 159 (m06-l04-q406): the bold option label is glued to the sentence
(«Página impar El salto de sección…»), with no colon or line break.
