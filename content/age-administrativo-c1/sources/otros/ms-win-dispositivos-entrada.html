Entrada e interacciones

En este artículo

Las aplicaciones WinUI controlan automáticamente una amplia variedad de entradas y se ejecutan en una variedad de dispositivos: no hay nada adicional que debe hacer para habilitar la entrada táctil, por ejemplo. Pero hay ocasiones en las que es posible que quiera optimizar la aplicación para determinados tipos de entrada o dispositivos. Por ejemplo, si estás creando una aplicación para pintar, puede que quieras personalizar la forma en que gestionas la entrada del lápiz óptico.

Las instrucciones de diseño y codificación de esta sección le ayudarán a personalizar la aplicación WinUI para tipos específicos de entradas.

Uso de las API de entrada de Windows Runtime en aplicaciones de escritorio de WinUI 3

Las aplicaciones de escritorio de WinUI 3 pueden usar directamente la mayoría de las API de Windows Runtime (WinRT), incluidas muchas API relacionadas con la entrada de datos de los espacios de nombres Windows.Devices.Input, Windows.Gaming.Input y Windows.UI.Input. No es necesario crear una aplicación para UWP para acceder a estas funcionalidades.

Hay algunas cosas que debe tener en cuenta:

  • Funciona en cualquier aplicación WinUI 3 — las propiedades del puntero (presión, inclinación y botón lateral), la detección de dispositivos, el acceso al hardware del mando de juego (Windows.Gaming.Input) y la entrada táctil y del ratón funcionan sin necesidad de ninguna configuración especial.
  • Requiere la identidad del paquete (MSIX): algunas API, como SpeechRecognizer y SpeechSynthesizer, requieren que la aplicación tenga la identidad del paquete. La plantilla de proyecto de WinUI 3 predeterminada usa el empaquetado MSIX, por lo que este requisito se cumple automáticamente para la mayoría de las aplicaciones.
  • Solo para UWP : las API que dependen de ApplicationView, CoreWindow o el GetForCurrentView patrón no están disponibles en las aplicaciones de escritorio. Esto incluye el seguimiento de la mirada (GazeInputSourcePreview) y la inyección de entrada (InputInjector). Para estas características, la documentación de referencia de UWP sigue siendo el mejor recurso.

Para obtener la lista completa de las API de WinRT admitidas y no admitidas en las aplicaciones de escritorio, consulte Windows Runtime API compatibles con aplicaciones de escritorio.

Tip

Los temas de esta sección que se vinculan a la documentación de UWP abarcan características que usan API solo para UWP. Todavía puede hacer referencia a estos temas para obtener instrucciones y conceptos de diseño, aunque las API no estén disponibles directamente en las aplicaciones de escritorio de WinUI 3.

Dispositivos de entrada

Topic Descripción
Identificación de dispositivos de entrada Identifique los dispositivos de entrada conectados a un dispositivo de aplicación Windows e identifique sus funcionalidades y atributos.
Puntero Reciba, procese y administre los datos de entrada procedentes de dispositivos señaladores, como la pantalla táctil, el ratón, el lápiz óptico y el panel táctil.
Lápiz y Windows Ink Administra propiedades de entrada específicas del lápiz, como la presión, la inclinación, el botón del cuerpo del lápiz y la detección del borrador.
Touch Controle la entrada táctil, lo que permite experiencias envolventes que los usuarios pueden explorar con confianza.
Ratón Controle la entrada del mouse en la aplicación, incluidos los clics de botón, la rueda de desplazamiento y el movimiento del puntero.
Keyboard Controla la entrada del teclado, una parte esencial de la experiencia de interacción e indispensable para la accesibilidad.
Controlador para juegos y control remoto Diseño para la entrada mediante mando de Xbox y mando a distancia. Las API Windows.Gaming.Input funcionan directamente en aplicaciones de escritorio de WinUI 3; el tema de UWP enlazado trata los patrones de diseño para pantallas de 10 pies.
Panel táctil Gestione la entrada del panel táctil, que combina la entrada multitáctil indirecta con la precisión de un dispositivo apuntador.
Varias entradas Diseñe la aplicación para que funcione con tantos tipos de entrada como sea posible para maximizar la flexibilidad, facilidad de uso y accesibilidad.
Entrada de texto personalizada Use las API principales de texto para recibir entrada de texto de cualquier servicio de texto compatible con dispositivos Windows, en cualquier idioma y desde cualquier tipo de entrada.
