Características en desuso para el cliente Windows

  • Se aplica a: ✅ Windows 11, ✅ Windows 10

En este artículo

Cada versión del cliente de Windows agrega nuevas características y funcionalidades. En ocasiones, las nuevas versiones también eliminan características y funcionalidades, a menudo porque agregaron una opción más reciente. En este artículo se proporcionan detalles sobre las características y funcionalidades que ya no se desarrollan en el cliente de Windows. Para obtener más información sobre las características que se quitaron, consulte Características de Windows eliminadas.

  • Para comprender la distinción entre desuso y eliminación, consulte Ciclo de vida de las características del cliente de Windows.
  • Para obtener más información sobre cómo encaja el desuso en el ciclo de vida de Windows, consulte Desuso: Qué significa en el ciclo de vida de Windows.
  • Para obtener más información sobre las características que se quitan al actualizar a Windows 11 desde Windows 10, consulte Obsolescencias y eliminaciones de características.

Las características de este artículo ya no se desarrollan activamente y podrían eliminarse en una actualización futura. Algunas características se reemplazaron por otras características o funcionalidades y algunas ahora están disponibles en otros orígenes.

Los estándares de Internet y los organismos reguladores no permitieron el uso de claves de 1024 bits en 2013, recomendando específicamente que las claves RSA deberían tener una longitud de clave de 2048 bits o más. Para obtener más información, consulte Transición de algoritmos criptográficos y tamaños de clave: documento de discusión (nist.gov). Este desuso se centra en garantizar que todos los certificados RSA usados para la autenticación del servidor TLS deben tener longitudes de clave mayores o iguales que 2048 bits para que Windows los considere válidos.

Los certificados TLS emitidos por las entidades de certificación (CA) Enterprise o de prueba no se ven afectados por este cambio. Sin embargo, recomendamos que se actualicen a claves RSA mayores o iguales a 2048 bits como práctica recomendada de seguridad. Este cambio es necesario para preservar la seguridad de los clientes de Windows que usan certificados con fines de autenticación y cifrado.		 Marzo de 2024
