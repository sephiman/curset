  Server» and quotes a definition for Windows 98/CE/NT/2000; the spec allows only pages that apply to Windows 11 or
  Microsoft 365 desktop. So no registry question, and conv2024_X·P1·51 and the «Herramientas del sistema» family get
  nothing from this part. **Coordinator decision needed:** either accept the page for a concept question («base de
  datos jerárquica central…», «perfiles para cada usuario, las aplicaciones instaladas… qué hardware existe»), or
  leave the official question uncovered.
- Windows+Flecha abajo «minimiza» (atajos) is not asked: `ms-win-acoplar.html` says Windows+flecha abajo places the
  app «en la parte inferior de la pantalla», so the two pages disagree. For the same reason no question keys or uses as
  distractor Windows+Alt+Flecha arriba/abajo, and q047 (Windows+Flecha arriba maximiza) uses no «mitad superior»
  statement as an option. A verifier may still read the acoplar page against q047; flagged here.
- Impr Pant, Cortana, Modo Dios, Reconocimiento de voz: not asked (disputed, retired, sin fuente).
- Not used as distractors because they are real alternatives on the pages: Windows+U and Windows+Pausa for «abre
  Configuración» (q001); msinfo32 for winver (q015); Alt+Esc, Ctrl+Alt+Tab for Alt+Tab (q050); F11 and

  questions.
