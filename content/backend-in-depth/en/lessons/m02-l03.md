# Linear structures and trees

## Linked lists, stacks and queues
<!-- bullets: 2.3.a -->

A `Deque` is a linear collection that supports element insertion and removal at both ends (`javadoc-deque#interface-deque-e`).

When a deque is used as a queue, elements are added at the end of the deque and removed from the beginning, which gives FIFO behavior (`javadoc-deque#interface-deque-e`).

Deques can also be used as LIFO stacks, and the interface should be used in preference to the legacy `Stack` class (`javadoc-deque#interface-deque-e`).

When a deque is used as a stack, elements are pushed and popped from the beginning of the deque (`javadoc-deque#interface-deque-e`).

:::esquema{kind=tabla title="Stack and Queue methods and their Deque equivalents"}
| Method | Equivalent Deque method | Citation |
| --- | --- | --- |
| `push(e)` of a stack | `addFirst(e)` | `javadoc-deque#interface-deque-e` |
| `pop()` of a stack | `removeFirst()` | `javadoc-deque#interface-deque-e` |
| `offer(e)` of a queue | `offerLast(e)` | `javadoc-deque#interface-deque-e` |
| `poll()` of a queue | `pollFirst()` | `javadoc-deque#interface-deque-e` |
| `peek()` of a queue or a stack | `peekFirst()` | `javadoc-deque#interface-deque-e` |
:::

Unlike the `List` interface, `Deque` does not provide support for indexed access to elements (`javadoc-deque#interface-deque-e`).

Deque implementations are not strictly required to prohibit null elements, but they are strongly encouraged to do so (`javadoc-deque#interface-deque-e`).

Null is used as a special return value by various methods to indicate that the deque is empty (`javadoc-deque#interface-deque-e`).

Each insert, remove and examine method of `Deque` exists in two forms: one throws an exception if the operation fails, the other returns a special value (`javadoc-deque#interface-deque-e`).

Deque implementations generally do not define element-based versions of `equals` and `hashCode`, but inherit the identity-based versions from `Object` (`javadoc-deque#interface-deque-e`).

A FIFO queue removes items in the same order they were added (`ods-1-2-interfaces#SECTION00421000000000000000`).

In a LIFO queue, the most recently added element is the next one removed (`ods-1-2-interfaces#SECTION00421000000000000000`).

Iterators allow the caller to remove elements from the underlying collection during the iteration with well-defined semantics (`javadoc-iterator#interface-iterator-e`).

The `ArrayStack` is an efficient way to implement a stack (`ods-2-1-arraystack-fast-stack-o#SECTION00513000000000000000`).

An `SLList` nearly implements the full set of `Deque` operations, and the only missing operation is removing from the tail (`ods-3-1-sllist-singly-linked-li#SECTION00612000000000000000`).

Removing from the tail of an `SLList` is difficult (`ods-3-1-sllist-singly-linked-li#SECTION00612000000000000000`).

In a `DLList`, the only expensive part of an operation is finding the relevant node (`ods-3-2-dllist-doubly-linked-li#SECTION00622000000000000000`).

Once the relevant node of a `DLList` is found, adding, removing or accessing the data at that node takes only constant time (`ods-3-2-dllist-doubly-linked-li#SECTION00622000000000000000`).

Linked list structures are well-suited to applications where references to list nodes can be obtained through external means (`ods-3-2-dllist-doubly-linked-li#SECTION00622000000000000000`).

In array-based `List` implementations, addition or removal requires shifting elements in the array and, in general, takes non-constant time (`ods-3-2-dllist-doubly-linked-li#SECTION00622000000000000000`).

When elements are removed from a `LinkedHashSet`, the hash table is used to find the relevant list node in constant time (`ods-3-2-dllist-doubly-linked-li#SECTION00622000000000000000`).

The snippet reverses a singly linked list, finds the middle node and a cycle with a slow and a fast pointer, uses an `ArrayDeque` as a stack and as a queue, and computes the next greater value of each array element with a stack of waiting indices.

```java snippet=m02-l03/LinkedStructures.java
import java.util.ArrayDeque;
import java.util.Arrays;
import java.util.Deque;

public class LinkedStructures {
    static class Node {
        final int value;
        Node next;

        Node(int value, Node next) {
            this.value = value;
            this.next = next;
        }
    }

    static Node of(int... values) {
        Node head = null;
        for (int i = values.length - 1; i >= 0; i--) {
            head = new Node(values[i], head);
        }
        return head;
    }

    static Node reverse(Node head) {
        Node previous = null;
        while (head != null) {
            Node next = head.next;
            head.next = previous;
            previous = head;
            head = next;
        }
        return previous;
    }

    static Node middle(Node head) {
        Node slow = head;
        Node fast = head;
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }
        return slow;
    }

    static boolean hasCycle(Node head) {
        Node slow = head;
        Node fast = head;
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
            if (slow == fast) {
                return true;
            }
        }
        return false;
    }

    static String show(Node head) {
        StringBuilder text = new StringBuilder();
        for (Node node = head; node != null; node = node.next) {
            text.append(node.value);
        }
        return text.toString();
    }

    static int[] nextGreater(int[] values) {
        int[] result = new int[values.length];
        Arrays.fill(result, -1);
        Deque<Integer> waiting = new ArrayDeque<>();
        for (int i = 0; i < values.length; i++) {
            while (!waiting.isEmpty() && values[waiting.peek()] < values[i]) {
                result[waiting.pop()] = values[i];
            }
            waiting.push(i);
        }
        return result;
    }

    public static void main(String[] args) {
        System.out.println("reversed " + show(reverse(of(1, 2, 3, 4, 5))));
        System.out.println("middle of five " + middle(of(1, 2, 3, 4, 5)).value);
        System.out.println("middle of four " + middle(of(1, 2, 3, 4)).value);

        Node looping = of(1, 2, 3);
        looping.next.next.next = looping.next;
        System.out.println("cycle found " + hasCycle(looping));
        System.out.println("cycle found in a plain list " + hasCycle(of(1, 2, 3)));

        Deque<Integer> stack = new ArrayDeque<>();
        stack.push(1);
        stack.push(2);
        stack.push(3);
        System.out.println("stack contents " + stack);
        System.out.println("stack pop " + stack.pop());

        Deque<Integer> queue = new ArrayDeque<>();
        queue.offer(1);
        queue.offer(2);
        queue.offer(3);
        System.out.println("queue poll " + queue.poll());

        System.out.println("next greater " + Arrays.toString(nextGreater(new int[] {2, 1, 2, 4, 3})));
    }
}
```

Reversing the list 1, 2, 3, 4, 5 by redirecting each `next` to the previous node prints `reversed 54321`.

The slow pointer advances one node while the fast pointer advances two, so on five nodes the snippet prints `middle of five 3`.

On four nodes the loop stops with the slow pointer on the third node, so it prints `middle of four 3`.

The fast pointer catches the slow one when the list loops back, so the snippet prints `cycle found true` for the looping list and `cycle found in a plain list false` for the other.

After pushing 1, 2 and 3, the stack prints as `stack contents [3, 2, 1]` and `pop` returns `3`, because `push` adds at the beginning.

After offering 1, 2 and 3 to the queue, `poll` returns 1, so the snippet prints `queue poll 1`.

The stack of waiting indices gives `next greater [4, 2, 4, -1, -1]` for the array 2, 1, 2, 4, 3: each element is answered by the first later element that is larger.

## Binary trees and binary search trees
<!-- bullets: 2.3.b -->

The maximum depth of a recursive traversal is the maximum depth of a node in the binary tree, which is the tree's height (`ods-6-1-binarytree-basic-binary#SECTION00912000000000000000`).

If the height of the tree is very large, the recursion could use more stack space than is available and cause a crash (`ods-6-1-binarytree-basic-binary#SECTION00912000000000000000`).

A non-recursive traversal uses an algorithm that relies on where it came from to determine where it will go next (`ods-6-1-binarytree-basic-binary#SECTION00912000000000000000`).

Without a parent field, a non-recursive traversal is still possible, but it has to use a `List` or `Stack` to keep track of the path from the current node to the root (`ods-6-1-binarytree-basic-binary#SECTION00912000000000000000`).

In a breadth-first traversal, the nodes are visited level-by-level starting at the root and moving down, visiting the nodes at each level from left to right (`ods-6-1-binarytree-basic-binary#SECTION00912000000000000000`).

Breadth-first traversal is implemented using a queue (`ods-6-1-binarytree-basic-binary#SECTION00912000000000000000`).

The breadth-first traversal does not fit the pattern of the recursive size and height functions (`ods-6-1-binarytree-basic-binary#SECTION00912000000000000000`).

The height of a node is computed from the heights of its two subtrees by taking the maximum and adding one (`ods-6-1-binarytree-basic-binary#SECTION00911000000000000000`).

A recursive method needs an elementary base case that can be solved by some other method, otherwise it will loop forever (`erickson-recursion#p3`).

The binary search tree property allows us to quickly locate a value (`ods-6-2-binarysearchtree-unbala#SECTION00921000000000000000`).

To add a value to a binary search tree, we first search for it, and if we find it there is no need to insert it (`ods-6-2-binarysearchtree-unbala#SECTION00922000000000000000`).

Otherwise the value is stored at a leaf child of the last node encountered during the search (`ods-6-2-binarysearchtree-unbala#SECTION00922000000000000000`).

The most time-consuming part of an addition is the initial search, which in the worst case takes time proportional to the height of the `BinarySearchTree` (`ods-6-2-binarysearchtree-unbala#SECTION00922000000000000000`).

The snippet walks one binary search tree in order with recursion and with a stack, collects its levels with a queue, finds a lowest common ancestor by comparing values, validates a second tree with two different checks, and takes the height of a chain of a million nodes.

```java snippet=m02-l03/TreeAlgorithms.java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Deque;
import java.util.List;
import java.util.Queue;

public class TreeAlgorithms {
    record Node(int value, Node left, Node right) {
    }

    static Node leaf(int value) {
        return new Node(value, null, null);
    }

    static void inorder(Node node, List<Integer> out) {
        if (node == null) {
            return;
        }
        inorder(node.left(), out);
        out.add(node.value());
        inorder(node.right(), out);
    }

    static List<Integer> inorderIterative(Node root) {
        List<Integer> out = new ArrayList<>();
        Deque<Node> path = new ArrayDeque<>();
        Node current = root;
        while (current != null || !path.isEmpty()) {
            while (current != null) {
                path.push(current);
                current = current.left();
            }
            current = path.pop();
            out.add(current.value());
            current = current.right();
        }
        return out;
    }

    static List<List<Integer>> levels(Node root) {
        List<List<Integer>> result = new ArrayList<>();
        Queue<Node> queue = new ArrayDeque<>();
        if (root != null) {
            queue.add(root);
        }
        while (!queue.isEmpty()) {
            List<Integer> level = new ArrayList<>();
            for (int remaining = queue.size(); remaining > 0; remaining--) {
                Node node = queue.remove();
                level.add(node.value());
                if (node.left() != null) {
                    queue.add(node.left());
                }
                if (node.right() != null) {
                    queue.add(node.right());
                }
            }
            result.add(level);
        }
        return result;
    }

    static int lowestCommonAncestorInBst(Node root, int p, int q) {
        Node node = root;
        while (true) {
            if (p < node.value() && q < node.value()) {
                node = node.left();
            } else if (p > node.value() && q > node.value()) {
                node = node.right();
            } else {
                return node.value();
            }
        }
    }

    static boolean localCheck(Node node) {
        if (node == null) {
            return true;
        }
        boolean leftOk = node.left() == null || node.left().value() < node.value();
        boolean rightOk = node.right() == null || node.right().value() > node.value();
        return leftOk && rightOk && localCheck(node.left()) && localCheck(node.right());
    }

    static boolean withinBounds(Node node, long low, long high) {
        if (node == null) {
            return true;
        }
        if (node.value() <= low || node.value() >= high) {
            return false;
        }
        return withinBounds(node.left(), low, node.value()) && withinBounds(node.right(), node.value(), high);
    }

    static int recursiveHeight(Node node) {
        if (node == null) {
            return -1;
        }
        return 1 + Math.max(recursiveHeight(node.left()), recursiveHeight(node.right()));
    }

    public static void main(String[] args) {
        Node tree = new Node(8,
                new Node(3, leaf(1), new Node(6, leaf(4), leaf(7))),
                new Node(10, null, new Node(14, leaf(13), null)));

        List<Integer> recursive = new ArrayList<>();
        inorder(tree, recursive);
        System.out.println("inorder " + recursive);
        System.out.println("iterative inorder " + inorderIterative(tree));
        System.out.println("levels " + levels(tree));
        System.out.println("lca of 4 and 7 " + lowestCommonAncestorInBst(tree, 4, 7));
        System.out.println("lca of 4 and 14 " + lowestCommonAncestorInBst(tree, 4, 14));

        Node invalid = new Node(10, leaf(5), new Node(15, leaf(6), null));
        System.out.println("local check " + localCheck(invalid));
        System.out.println("bounds check " + withinBounds(invalid, Long.MIN_VALUE, Long.MAX_VALUE));

        Node chain = null;
        for (int i = 1_000_000; i >= 1; i--) {
            chain = new Node(i, null, chain);
        }
        try {
            recursiveHeight(chain);
        } catch (StackOverflowError e) {
            System.out.println("recursive height overflows the stack");
        }
        System.out.println("iterative levels " + levels(chain).size());
    }
}
```

Both the recursive and the stack-based in-order traversal print `[1, 3, 4, 6, 7, 8, 10, 13, 14]`, the values in ascending order.

The queue gives `levels [[8], [3, 10], [1, 6, 14], [4, 7, 13]]`, one list per level.

The lowest common ancestor of 4 and 7 prints as `lca of 4 and 7 6` and that of 4 and 14 as `lca of 4 and 14 8`, the first node whose value falls between the two.

On a tree whose node 15 has the left child 6, the check of each node against its own children prints `local check true`, and the check against the bounds inherited from the ancestors prints `bounds check false`.

The recursive height of the chain of a million nodes ends in a `StackOverflowError`, and the snippet prints `recursive height overflows the stack`, while the queue-based version prints `iterative levels 1000000`.

## Heaps, top-K problems and tries
<!-- bullets: 2.3.c -->

The head of a `PriorityQueue` is the least element with respect to the specified ordering (`javadoc-priorityqueue#class-priorityqueue-e`).

`PriorityQueue.offer` throws `NullPointerException` if the specified element is null (`javadoc-priorityqueue#offer(java.lang.Object)`).

`PriorityQueue.offer` throws `ClassCastException` if the element cannot be compared with the elements currently in the queue according to the queue's ordering (`javadoc-priorityqueue#offer(java.lang.Object)`).

`PriorityQueue.poll` retrieves and removes the head of the queue, or returns null if the queue is empty (`javadoc-priorityqueue#poll()`).

A priority queue does not permit null elements (`javadoc-priorityqueue#class-priorityqueue-e`).

A priority queue always removes the smallest element from the queue, breaking ties arbitrarily (`ods-1-2-interfaces#SECTION00421000000000000000`).

Eytzinger's method represents a complete binary tree as an array by laying out the nodes of the tree in breadth-first order (`ods-10-1-binaryheap-implicit-bi#SECTION001310000000000000000`).

In that layout the root is stored at position 0, the root's left child at position 1 and the root's right child at position 2 (`ods-10-1-binaryheap-implicit-bi#SECTION001310000000000000000`).

In the `BinaryHeap` code the left child of index `i` is at `2*i + 1`, the right child at `2*i + 2` and the parent at `(i-1)/2` (`ods-10-1-binaryheap-implicit-bi#SECTION001310000000000000000`).

In a `BinaryHeap` the smallest value is stored at position 0, the root (`ods-10-1-binaryheap-implicit-bi#SECTION001310000000000000000`).

A `BinaryTrie` encodes each integer as a root-to-leaf path (`ods-13-1-binarytrie-digital-sea#SECTION001610000000000000000`).

The snippet keeps the three largest of seven numbers in a `PriorityQueue` by polling the least element whenever the queue grows past three, checks the index arithmetic of a heap, and counts the words below a prefix in a trie of characters.

```java snippet=m02-l03/HeapAndTrie.java
import java.util.ArrayList;
import java.util.Collections;
import java.util.Comparator;
import java.util.HashMap;
import java.util.List;
import java.util.Map;
import java.util.PriorityQueue;

public class HeapAndTrie {
    static class Trie {
        private final Map<Character, Trie> children = new HashMap<>();
        private int wordsBelow;

        void insert(String word) {
            Trie node = this;
            node.wordsBelow++;
            for (char c : word.toCharArray()) {
                node = node.children.computeIfAbsent(c, key -> new Trie());
                node.wordsBelow++;
            }
        }

        int countWithPrefix(String prefix) {
            Trie node = this;
            for (char c : prefix.toCharArray()) {
                node = node.children.get(c);
                if (node == null) {
                    return 0;
                }
            }
            return node.wordsBelow;
        }
    }

    public static void main(String[] args) {
        int k = 3;
        PriorityQueue<Integer> smallestOfTheLargest = new PriorityQueue<>();
        for (int value : new int[] {5, 1, 9, 3, 7, 8, 2}) {
            smallestOfTheLargest.offer(value);
            if (smallestOfTheLargest.size() > k) {
                smallestOfTheLargest.poll();
            }
        }
        System.out.println("kth largest " + smallestOfTheLargest.peek());
        List<Integer> topK = new ArrayList<>(smallestOfTheLargest);
        Collections.sort(topK);
        System.out.println("top 3 " + topK);

        PriorityQueue<Integer> maxHeap = new PriorityQueue<>(Comparator.reverseOrder());
        maxHeap.addAll(List.of(5, 1, 9, 3));
        System.out.println("max-heap head " + maxHeap.peek());

        int i = 4;
        System.out.println("children of 4: " + (2 * i + 1) + " and " + (2 * i + 2) + ", parent of 4: " + (i - 1) / 2);

        try {
            smallestOfTheLargest.offer(null);
        } catch (NullPointerException e) {
            System.out.println("null is rejected");
        }

        Trie trie = new Trie();
        for (String word : new String[] {"car", "card", "care", "cat", "dog"}) {
            trie.insert(word);
        }
        System.out.println("words with prefix car: " + trie.countWithPrefix("car"));
        System.out.println("words with prefix ca: " + trie.countWithPrefix("ca"));
        System.out.println("words with prefix x: " + trie.countWithPrefix("x"));
    }
}
```

The queue keeps at most three elements, and `poll` drops the least one whenever a fourth arrives, so the snippet prints `kth largest 7` and `top 3 [7, 8, 9]`.

With `Comparator.reverseOrder()` the head is the greatest element, so the snippet prints `max-heap head 9`.

For index 4 the formulas give `children of 4: 9 and 10, parent of 4: 1`.

Offering `null` prints `null is rejected`.

In the trie of `car`, `card`, `care`, `cat` and `dog`, the prefix `car` matches 3 words, `ca` matches 4 and `x` matches none, so the snippet prints `words with prefix car: 3`, `words with prefix ca: 4` and `words with prefix x: 0`.

## Key points

- A `Deque` serves as a stack through `push` and `pop` at the beginning, and as a queue by adding at the end and removing from the beginning.
- Deque implementations are strongly encouraged to prohibit null, because null is the special return value for an empty deque.
- In a doubly linked list, only finding the node is expensive, and an `SLList` cannot remove from its tail cheaply.
- A slow pointer and a fast pointer find the middle of a list and a cycle in the snippet.
- A recursive traversal uses stack space proportional to the height of the tree, and a deep tree can crash it.
- Breadth-first traversal visits level by level with a queue, and a check of each node against its own children does not validate a binary search tree.
- `PriorityQueue` rejects null and incomparable elements, and keeping a queue of size K with the least element at its head yields the K largest values.
- A `BinaryHeap` stores the tree in an array with the root at position 0, children at `2*i + 1` and `2*i + 2` and the smallest value at the root.
